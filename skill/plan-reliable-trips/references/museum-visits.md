# 博物馆、展览、纪念馆与大型展馆规则

目的地研究可以轻量扫描博物馆、展览、纪念馆、遗址馆和小型专业馆；仅在用户明确点名、展馆已经进入主路线，或扫描发现它构成目的地核心价值时读取本文件深入研究。首府、知名城市或历史文化城市只提高扫描概率，不自动触发完整模块。涉及馆店购买时按普通偏好直接给建议；携带与海关合法性按 `entry-and-transit.md` 判断。

## 1. 把展馆作为正式旅行内容

- 不把展馆研究限制在世界级博物馆城市。前往一个国家 / 地区的首府、知名城市或历史文化城市时，主动检查是否有能解释该地历史、文明、艺术、产业或重要事件的高价值馆；即使规模较小，只要内容不可替代且与本次行程匹配，也应进入正式候选。
- 馆藏和博物馆体系构成目的地核心价值时，不得把展馆放在攻略末尾作为“下雨备选”或预约提醒；其他目的地发现单个高价值馆时，也不能因为当地“不以博物馆出名”而忽略。
- 先判断本次旅行中展馆是 `核心锚点 / 重要补充 / 条件候选 / 不建议纳入`，再决定天数、住宿区域、交通、用餐和其他户外节点。
- 搜索国家级综合馆、艺术馆、考古 / 历史馆、专题馆、纪念馆、名人故居、遗址博物馆、科学技术馆、临展和小型专业馆；不因规模小或游客少而漏掉难以替代的馆藏与叙事。
- 同类馆过多时比较后取舍，不机械把所有“著名博物馆”塞进行程，也不连续安排内容高度重复的馆。

## 2. 搜索候选并判断真实价值

除官方页面和馆藏数据库外，结合当地文化主管机构、博物馆协会、大学 / 研究机构、专业策展或艺术史资料、可信本地文化媒体和近期参观信息。社交平台、榜单、评分和访客数量只用于发现候选或现场问题，不证明价值。

对每个重要候选分别检查：

| 维度 | 必须回答的问题 |
|---|---|
| 馆藏与内容 | 真正公开展出的核心藏品、遗址或展览是什么，而不是机构总收藏量或宣传口号？ |
| 不可替代性 | 是否只能在这里理解或看到，还是已被本次其他馆完整替代？ |
| 展陈与叙事 | 展线、实物、场景、文字和多媒体能否形成清楚而有价值的理解？ |
| 本次匹配 | 与用户兴趣、历史背景、同行者、可用时间和语言条件是否匹配？ |
| 中文可理解性 | 中文标识、导览、讲解或替代方案能否让用户真正看懂？ |
| 时间与成本 | 门票、讲解、排队、馆内距离、疲劳和绕行是否值得？ |
| 当前可见性 | 核心展厅和代表展品是否开放、在展，是否外借、维修或需要另票？ |

### 识别“名气大但实际参观价值弱”

- 区分建筑知名度、机构名气、收藏总量和本次实际可参观内容；四者不能互相替代。
- 核验宣传中的代表展品是否长期陈列、当前在展、真品还是复制 / 复原展示，以及用户能否进入对应展区。
- 检查是否主要依赖打卡建筑、短期营销、旅游团惯性、夸大的“必去”称号或单件明星展品，却需要付出长队、高票价和大量绕行。
- 若展陈陈旧、叙事薄弱、语言障碍严重、核心区域关闭或与其他馆高度重复，应降级并给出更好的替代；只能根据可观察证据说明，不空泛地说“没意思”。

### 寻找小众但真正有价值的馆

- 使用当地语言搜索专题馆、大学馆、遗址馆、社区历史馆、工艺馆、名人故居和高质量临展。
- 优先保留藏品或场址不可替代、策展清楚、与本次主题高度相关的馆，而不是为了“小众”本身推荐。
- 小馆的短开放时间、预约制、志愿者讲解和交通成本必须一并核验；价值高但执行困难时给条件式方案。

## 3. 中文理解与讲解支持

用户以中文为母语且英语理解能力有限。对进入最终路线的重点展馆，默认主动核验：

- 馆内中文展签覆盖程度，不能因官网有中文页面就推断展厅有中文；
- 官方中文地图、纸质手册、语音导览器、App、小程序、二维码内容、字幕和定时中文讲解；
- 导览是否覆盖本次核心展区，费用、押金、耳机、设备兼容、下载地区、网络、离线使用和归还时间；
- 中文名称与当地可检索名称是否一致，机器翻译是否可能混淆人名、年代、朝代、艺术流派或考古术语；
- 没有中文支持时，英文展签的密度与难度，以及展品是否能在缺少文字的情况下理解。

重点馆默认准备一份简洁的中文参观辅助：

1. 入馆前可读完的背景主线，不复制百科全书；
2. 本次真正值得看的展区与代表展品；
3. 中英文 / 当地语言名称和馆内定位；
4. 每件重点展品“为什么重要、现场看什么细节”；
5. 容易混淆的年代、人物、文明或艺术术语；
6. 官方中文导览不足时的可靠补充与离线翻译方案，并说明机器翻译局限。

## 4. 判断是否需要中文导游

不得默认“国外博物馆都需要请导游”，也不得因为费用较高就默认不请。对每个重点馆比较：

- `官方中文人工讲解`：优先核验是否为定时团、预约团还是私人讲解；
- `官方中文语音 / App`：覆盖是否足够、路线是否清楚、能否离线使用；
- `持证或馆方认可的中文私人导游`：适合复杂文明、考古、艺术史、纪念历史或展区庞大的馆；
- `中文行前导读 + 自助参观`：适合官方导览充分、视觉理解较强或停留较短的馆。

以下情况提高请中文导游的价值：馆藏背景复杂、展厅庞大且动线混乱、中文信息很少、本次对该主题重视、多人分摊后成本合理，或有限时间内需要高质量取舍。官方中文语音已经充分、馆内以直观建筑 / 场景为主、导游内容与兴趣不匹配，或导游费远高于增益时，可不请并说明替代方案。

### 导游与讲解价格必须按本次核验

- 使用确切日期、人数、语言、时长和馆名，区分按人、按团、按小时、半日和全日价格；同时给当地货币与人民币约值。
- 分开列门票、临展票、导览器、导游费、语言附加费、交通、耳机、平台费、税费和惯例小费；说明哪些已含、哪些另付。
- 核验集合点、是否陪同入馆、门票由谁购买、取消规则、迟到处理和是否允许馆内外部导游。
- “免排队”只能按官方票种和入口规则说明；私人导游或第三方服务不能自动证明有优先入场权。
- 重要或高价私人讲解优先比较官方渠道与至少两个可靠、合法运营方；可核验时检查导游资质、语言能力、近期详细评价和真实讲解范围。
- 无法获得公开价格时，不编造“通常价格”。给出询价对象、需要提交的条件和可复制询价文字，再以书面报价比较。

最终必须给明确结论：`建议请中文导游 / 官方中文语音足够 / 建议行前导读后自助 / 取决于预算或兴趣`，并解释增加的理解价值是否值得费用和时间。

## 5. 设计馆内游览方法与路线

- 根据用户时间和兴趣提供有实际差异的精华路线与深度路线；馆很小时不机械生成多套时长，馆很大时不得用“全部逛完”掩盖取舍。
- 路线按真实入口、楼层、展区连接、单向通行、电梯 / 楼梯、拥堵和出口设计，优先保护不可替代展厅和可能提前关闭的区域，减少无意义折返。
- 每个重点展区或展品写明：中文名、当地可检索名、馆内位置、重要性、现场观察重点、建议停留和是否需要讲解。
- 把安检、寄存、取导览、找路、排队、休息、卫生间、餐饮、拍摄和馆店计入总时长。
- 大馆安排认知与体力休息；同一天多馆时考虑信息疲劳、站立时间和闭馆时间，不只看地图距离。
- 核心展品临时不展、展厅关闭、入场过晚或体力不足时，给可直接执行的缩短路线，而不是让整馆方案失效。

馆内逐段路线可使用：

| 时间 / 顺序 | 展区或展品 | 为什么值得看 | 现场看什么 | 中文理解方式 | 移动 / 休息提醒 |
|---|---|---|---|---|---|

## 6. 入场、现场条件与摄影

- 核验准确入口、预约、实名、常设展 / 临展 / 分馆票、闭馆日、最后入场、再入场、安检、寄存、无障碍和儿童政策。
- 重要展品可能轮换、外借或关闭时设置临行复核，不保证一定在展；官方馆藏数据库也不等于正在陈列。
- 核验馆内地图、休息座椅、卫生间、饮水、咖啡厅和馆店关闭时间；这些会改变长时间参观的可执行性。
- 先轻量判断建筑、展厅和允许拍摄展品的摄影价值；只有达到 SKILL 的摄影触发条件时才读取 `photography.md`。无论是否加载摄影模块，都要核验闪光灯、三脚架、自拍杆、商业拍摄、版权和安保限制。
- 涉及纪念馆、灾难、战争、墓葬、遗骸或宗教对象时，补充行为与摄影伦理，不以“出片”为最高目标。

## 7. 与整条路线共同优化

- 重点馆可以成为半日或整日锚点；围绕其入口、预约和闭馆时间安排交通、用餐、周边街区与其他景点。
- 博物馆密集型目的地先分配真正值得用于展馆的天数，再做馆与馆的取舍；不要把大馆都压缩成一小时打卡。
- 中文导游或定时中文讲解一旦预订，应作为硬锚点并预留迟到缓冲。
- 结合住宿基点评估早场入馆、闭馆后活动、夜间返回和携带馆店商品，不把展馆路线与住宿、餐饮分开规划。

## 8. 交付方式

目的地含多个重要展馆时，先交付价值与语言支持比较：

| 展馆 | 真实核心价值 | 本次适配与重复度 | 中文支持 | 建议停留 | 中文导游结论 | 门票与讲解总成本 | 主要风险 | 信息确认情况 |
|---|---|---|---|---|---|---|---|---|

- 对最终纳入的重点馆给出馆内精华路线、理解重点、讲解选择、真实总时长和失败缩短方案。
- 对知名但未纳入的馆说明真实原因；对小众但高价值的馆说明不可替代性和额外执行成本。
- 动态价格、开放、展览、展品位置、中文服务和导游库存注明核验日期；临行前复查。
- 深度背景只围绕本次选中的展品和主题展开，不堆砌整部艺术史或文明史。
