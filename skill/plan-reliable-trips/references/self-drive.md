# 自驾、租车与公路旅行规则

仅在本次包含自驾、租车或公路旅行时读取。包车但用户不驾驶时回到 SKILL 判断是否加载 `taxi-charter.md`；租车车辆保障按本文件处理。整趟旅行险由用户自行安排，只有出现额外保险触发条件时才读取 `travel-insurance.md`。

## 1. 先确认合法性与适用条件

- 优先按驾照签发地、驾驶者年龄、目的地、日期和车辆类别，核验驾照、翻译件 / 国际驾驶许可、最低与最高年龄、驾龄及附加驾驶员条件。只有当地法律或租车资格明确依赖居住地或旅行证件类别时才补问，不把护照签发地列为默认问题。
- 把道路法规、租车公司合同、保险 / 豁免条款和经验建议分开。某租车公司接受证件，不代表当地法律一定允许驾驶；反之亦然。
- 核验靠左或靠右行驶、方向盘位置、常见优先权、速度与酒驾规则。用户不熟悉通行方向时，把落地疲劳、第一天取车地点和首段道路复杂度纳入可行性判断。
- 核验环保 / 低排放区、拥堵区、季节封路、轮渡装车、边境和特殊道路许可；所有国家或地区规则都按本次日期动态核验，不使用固定国家清单。

## 2. 统一报价与合同口径

比较租车方案时至少统一：

- 取还车地点、完整当地日期和时间、租期计费天数、营业时间外服务、异地还车和跨境费；
- 车型组还是保证车型、座位与可用行李空间、变速箱、燃料 / 电动、里程限制和超里程费；
- 主驾驶与附加驾驶员、年轻 / 高龄驾驶员、儿童座椅、冬季装备、道路救援和其他必需附加项；
- 基础租金、税费、地点附加费、押金 / 预授权、付款卡要求、取消条款及取车时可能追加的费用；
- 整段行程的燃油 / 充电、收费公路、停车、轮渡和必要清洁成本。

不要只比较首页“每天起价”。明确付款人、主驾驶人和持卡人是否必须一致，以及借记卡、虚拟卡或第三方付款是否被接受，但不索取卡号。

取车时记录车身、轮胎、轮毂、玻璃、车顶、底盘可见处、内饰、油量 / 电量和里程；让既有损伤写入交车单并保存带时间的照片或视频。还车时按合同取得油量 / 电量、车况、时间和最终签收证明，不能仅凭“钥匙投入箱中”推断责任结束。

## 3. 车辆保障、责任与免赔额

先确认当地强制第三者责任保障，再逐项阅读合同或保单原文：

- CDW / LDW、碰撞损失、盗抢、第三者责任的保障对象、额度和免赔额 / 自负额；
- 所谓 `Super CDW`、`Zero excess` 或“全险”是否真的把免赔额降为零，以及轮胎、玻璃、车顶、底盘、内饰、钥匙、拖车、误加燃料和单方事故是否排除；
- 未授权驾驶员、越界 / 轮渡、非铺装路、超速、酒精、错误用途、迟报事故或未取得警方文件是否导致保障失效；
- 道路救援是否包含拖车、换胎、亏电、锁车、送油 / 充电，还是只提供呼叫渠道并另行收费；
- 发生事故后是否必须先联系租车公司 / 保险协助、取得警方报告、使用指定维修或拖车，以及报案时限。

区分“保险”“损失豁免”和押金。第三方补充保障或信用卡附赠租车保障可能采用先赔后报、只保车损、不保第三者责任，或要求用指定卡支付全部租金并拒绝租车公司保障；必须核验发卡机构、保险人和租车合同三方条件，不能仅凭卡片等级推断已覆盖。

人身意外、个人财物和旅行医疗属于整趟旅行保障，不把车辆 CDW / LDW 当作替代；只有本次需要专项提醒或用户主动询问时，才按 SKILL 路由读取 `travel-insurance.md`。

## 4. 燃油与充电政策

- 明确满油取还、同量取还、预购燃油或按使用量收费；比较未加满的单价、服务费和附近加油时间，避免把预购便利写成必然省钱。
- 核验正确燃料标识、油箱盖说明、支付方式、押金、夜间可用性和偏远路段最后可靠加油点；保留加油小票和还车油表照片。
- 电动车核验真实续航余量、接口、快慢充、运营商 / 漫游、账户与支付、停车或占位费、住宿充电、冬季 / 山路影响和至少一个备用站。实时空闲桩位只能作为临行与途中信息，不能提前保证。
- 把加油 / 充电绕行、排队和还车前补能写入门到门时间与总成本。

## 5. 收费道路、通行标签与限制区

- 按国家、地区和具体路线核验 vignette、ETC / toll tag、电子车牌收费、收费站现金 / 卡和租车公司代缴方案；说明购买 / 激活时点、适用道路、有效期、车辆类别和证据保存方式。
- 区分道路通行费、租车公司设备租金、每次使用费和事后行政处理费。不要把“租车公司会代扣”理解为没有额外费用。
- 核验跨区或跨国后原设备是否继续适用；电子收费无人工窗口时给出车牌查询和付款期限。
- 对低排放区、拥堵区、居民区、公交专用道和城市许可，核验租车是否已登记以及游客能否自行申请。

## 6. 停车、罚单与后续账单

- 核验确切停车场入口、预约、开放时间、限高 / 限长、车牌登记、收费单位、过夜规则和入口步行距离。
- 区分合法车位、装卸区、居民位、限时位、私人停车场和临时游客做法；不把路边有车停当作合法依据。
- 说明停车盘、App、纸票展示、离场前缴费、车牌输入和充电车位规则。提前准备 App 无法注册、机器拒卡、停车已满或道路关闭的替代。
- 罚单、拖车或通行费通知必须使用主管机构或租车公司的正式入口处理；区分原始罚款、逾期增加额和租车公司转交通知 / 行政费，保存申诉、付款和租车合同证据。不要点击来源不明的短信付款链接。
- 还车后保留合同、交还证明、车况影像、油费 / 充电和通行费凭证，直到押金释放且合理的后续收费窗口过去；异常扣款先索取逐项依据，再按租车公司、保险 / 发卡机构和主管机构流程处理。

## 7. 车辆、道路和季节匹配

- 按人数、真实行李体积、儿童座椅、道路宽度、坡度、铺装、离地间隙、天气与停车空间选择车辆，不盲目推荐更大或四驱车型。
- 核验本次日期的雪胎、雪链、防滑设备和携带 / 使用义务，确认租车提供、安装限制、限速和练习条件；“配有四驱”不等于满足法律或制动安全要求。
- 标出狭窄、陡峭、临崖、非铺装、易结冰、动物出没、缺少补给或不宜夜驾的路段，并提供绕行或改公共交通的触发条件。
- 跨境、上岛轮渡、异地还车前取得租车公司书面许可，核验车辆文件、道路救援、保障地域和当地通行设备；“申根 / 无边检”不等于合同允许跨境。

## 8. 驾驶时间、通行方向与疲劳

- 使用门到门时间，并加入取还车、验车、加油 / 充电、休息、边境 / 轮渡、找车位和步行接驳。地图最短时间不是计划时间。
- 遵守任务卡中每位驾驶者的舒适时间和绝对上限；多名司机不代表车辆总驾驶上限自动翻倍。
- 避免把长途飞行、时差、睡眠不足后的首次靠异侧驾驶安排在复杂市中心、黑夜或恶劣天气。必要时先住宿、改在郊区取车或使用公共交通离开城市。
- 规划可执行的休息点和驾驶员轮换；出现困倦、反应迟缓或天气恶化时立即停止继续压行程，不用咖啡或“还剩一点”代替休息。
- 不接受夜驾时，根据当地日落、道路、天气和停车时间倒推最晚出发。饮酒、镇静药物或影响驾驶能力的活动与当日驾驶不得冲突。

## 9. 导航、故障与事故流程

- 出发前保存离线地图、路线号、住宿 / 停车当地语言地址、燃油 / 充电点和替代道路；核验手机覆盖、车载系统、充电线 / 支架及目的地使用手机的法律。
- 不盲从导航进入封路、季节道路、窄巷、非铺装路或禁止车辆区域；关键山区、边境和轮渡段同时核验道路主管机构或运营方信息。
- 保存租车公司、道路救援、保险协助、当地紧急号码和车辆位置 / 车牌信息。无信号区域提前安排报备或卫星通信，相关户外风险同时执行 `hiking-rules.md`。
- 故障时先把人和车辆置于法律允许的安全位置，使用警示设备并按当地规则联系救援；不要在高速或危险路肩自行维修。
- 事故时优先救助与现场安全，随后按当地法律和合同联系紧急服务、警方、租车公司与保险协助；记录时间、位置、车辆、损伤、对方与证人所需信息，但不在不理解内容时签署责任承认。

## 10. 交付要求

自驾方案至少给出：

1. `可驾驶 / 条件可驾驶 / 不建议自驾 / 尚无法判断` 及关键证据；
2. 驾照、年龄、驾驶方向、跨境 / 轮渡和季节装备条件；
3. 同口径租车总价、押金、燃油 / 充电、收费、停车和异地还车成本；
4. 车辆保障缺口、免赔额、主要排除与道路救援；
5. 每日门到门驾驶表、休息 / 轮换、最晚出发和替代交通；
6. 加油 / 充电、收费道路、停车、低排放区和离线导航方案；
7. 取还车证据清单及故障、事故、罚单和异常扣款处理入口；
8. 所有动态规则的来源、核验日期和临行复核节点。
