# 自驾与公路旅行规则

仅在本次包含自驾、租车或包车线路设计时读取。

## 1. 合法与可用条件

- 核验本次适用的驾照、翻译件、最低年龄、保险、押金、跨境和异地还车规则。
- 核验收费、限行、环保区、停车、冬季装备、轮渡和道路关闭。
- 区分租车公司规则、道路法规和经验建议，不混为一谈。

## 2. 驾驶时间

- 使用门到门时间，并加入取还车、加油 / 充电、停车找位、步行接驳和休息。
- 遵守任务卡中的单日舒适时间和绝对上限；有多名司机不代表车辆总驾驶上限自动翻倍。
- 地图最短时间不是计划时间。节假日、山区、边境、轮渡和冬季条件增加独立缓冲。
- 不接受夜驾时，按当地日落、道路条件和停车时间倒推最晚出发。

## 3. 车辆与道路匹配

- 按人数、行李、儿童座椅、路况和天气选择车辆，不盲目推荐更大车型。
- 电动车路线核验充电网络、接口、支付和备选站，不承诺实时空闲桩位。
- 标出狭窄、陡峭、非铺装、结冰、缺少补给或不建议夜驾的路段，并给替代道路。
- 饮酒活动与当日驾驶不得冲突。

## 4. 停车与失败方案

- 核验目的地实际停车点、预约、限高、收费、开放时间和入口步行距离。
- 重要节点准备停车已满、道路关闭、车辆故障或恶劣天气时的替代方案。
- 不把路边临时停车或游客经验写成合法停车保证。
