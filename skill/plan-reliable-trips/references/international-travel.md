# 出境、跨境与国外旅行规则

仅在单次任务涉及国外目的地、跨境或国际中转时读取。不要把本模块写入国内旅行攻略。

## 1. 先确定适用身份和行程

- 入境、签证和过境规则取决于旅行证件签发国或地区、出发地、中转地、目的地、停留时长和旅行目的。
- 只询问判断规则所需的信息，不索取证件号码、详细住址或支付账户信息。
- 不把其他国籍旅客、永久居民或网络经验的规则套用给用户。

## 2. 必须动态核验的事项

- 签证、免签、电子许可、入境卡、停留期限和护照有效期要求；
- 国际中转是否需要过境签、入境、重新托运行李或更换机场；
- 海关、检疫、药品、食品、无人机、驾驶、摄影和保护区规定；
- 旅行保险、医疗、疫苗和紧急救助要求；
- 航空公司值机、行李、联程与误机处理；
- 当地支付、现金、银行卡、通信和交通票务的当前可用方式。
- 口岸是否存在经多来源反复报告的非官方索费，以及餐厅、住宿等本次场景中的税费、服务费、小费和其他附加费。

优先使用目的地政府、移民、使领馆、海关、机场、航空公司和运营方的直接页面。高风险或不可逆事项至少使用两个独立来源，其中一个必须是主管机构。

## 3. 通关准备、机场服务与非官方索费

### 默认检查正常通关准备

- 检查可提前完成的电子签证 / ETA、入境卡、海关申报、健康申报、预登记、在线值机和证件预审；
- 检查本次旅客是否符合官方电子闸机、自动边检、可信旅客或注册旅客计划，并说明资格、入口、提前量和普通通道备选；
- 把签证 / 落地许可、边检、海关、检疫、提取行李、重新托运和跨航站楼分别计算，避免用“快速通关”笼统代替真实流程。

机场或航空公司的付费快速通道、礼宾、接送和转机协助不是国外旅行的默认必查项。只有用户主动询问，或本次确有紧张转机、行动协助等明显需求时才研究。必须写清它实际覆盖的是值机、安检、休息室、行李、引导、边检还是海关；机场商业服务不得被写成能保证移民准入、跳过海关检查或获得公职人员特殊照顾。若主管机关确有公开、合法且适用的付费服务，也只能依据主管机构页面说明，不从第三方宣传推断资格或效果。

### 识别口岸非官方索费

- 正式签证费、入境 / 出境费、落地签费或其他政府收费，必须核验主管机构公布的金额、适用对象、官方支付渠道和收据要求；
- 若官方旅行提示和多个可信近期来源反复指出某个口岸、流程或人群存在索要“手续费”“小费”“加速费”或其他非官方款项的风险，必须在出发前明确预警，并把正式收费与非官方索要分开；不得因个别帖子给整个国家贴标签；
- 不建议、暗示或常态化向边检、海关、警察或其他公职人员付款。安全可行时，可礼貌要求对方说明收费名称和官方依据、使用正式窗口 / 电子渠道并出具收据，必要时请求值班主管；
- 不鼓励争吵、肢体对抗或在当地禁止时偷拍偷录。人身与证件安全优先；先离开危险场景，再按当地适用方式联系旅游警察、机场 / 口岸运营方、使领馆或领事保护，并保留合法取得的时间、地点、人员特征和凭证。

## 4. 国际交通与中转

- 使用完整当地日期、星期、时区和航站楼；跨越日期变更线时明确抵达日期。
- 分开计算值机、安检、边检、提取行李、重新托运、航站楼或机场转移。
- 不把航空公司标注的最短转机时间当作用户一定赶得上的保证。
- 识别联程与非联程、同机场与跨机场、受保护转机与自行承担误机风险。
- 核验末班公共交通；深夜到达必须有可执行的住宿或接驳方案。

## 5. 国家与地区的实际运行习惯和账单收费

不能只写法律和官方流程，还要研究会影响旅行体验的普遍在地做法，并把“法规”“行业惯例”“近期旅客经验”分开标记。

至少按本次行程检查：

- **小费**：哪些行业通常给、是否为自愿、是否已有服务费、常见计算口径、现金还是刷卡、不给是否失礼，以及如何避免重复支付；
- **服务效率**：酒店行李、门童、礼宾、司机、导游等服务场景中，小费是否属于正常惯例；不得延伸到公职人员或违法付费；
- **时间与营业**：周末、宗教日、午休、罢工、节庆和预约习惯；
- **身份与安检**：是否经常需要携带证件、实名票、安检或住宿登记；
- **文化与行为**：着装、宗教、饮酒、公共礼仪、摄影禁忌和性别相关规则；
- **常见摩擦**：出租车议价、旅游税、服务费、押金、骗局、临时加价和现金找零。
- **议价与特殊交通风险**：机场 / 口岸上车点、持牌出租车、实际可用叫车平台、平台外交易、包车报价、行李控制，以及马车、骑乘、突突车、摩托车、传统船只等的计价、安全、隐性收费与动物福利；涉及这些场景时执行 `taxi-charter.md`。

酒店、餐厅和其他消费场景必须把下列项目分开，不能统称为“税费”或“小费”：

- 法定增值税、销售税或消费税；
- 强制服务费；
- 城市税、旅游税、住宿税或度假费；
- 餐位费、面包 / 饮水费、最低消费或套餐附加项；
- 银行卡、外币、平台或预订附加费；
- 顾客自主决定的可选小费。

对本次会遇到的场景说明：收费名称、官方或合同 / 菜单依据、常见金额或比例、是否强制、是否通常已含在标价或预订总价中、由谁收取、如何支付、开票 / 收据方式，以及已收服务费后是否仍习惯另给小费。金额和国情建议必须注明来源性质与核验时间；不能用一个国家的惯例推断邻国、所有城市或所有商户。

遇到不明收费时，攻略给出以下处理顺序：

1. 先索取逐项账单或住宿费用明细，不只接受一个口头总数；
2. 礼貌询问收费名称、比例、强制 / 可选属性，以及菜单、预订条款或法规依据；
3. 对照点单菜单、预订确认和已公布价格，有疑问时请值班经理或平台客服解释并更正；
4. 服务费已经包含时，避免在不知情的情况下重复给小费；刷卡前核对终端金额、币种与账单一致；
5. 不把拒付和现场冲突设为统一答案。以人身和证件安全为先，按当地法律安全处理，保留收据、预订页面和合法取得的照片，再视情况使用消费者主管机构、旅游警察、预订平台或发卡行争议流程。

## 6. 支付、换汇和现金

- 先执行 `public-transit.md` 的支付兼容与备份规则。用户已确认国外旅行可以提前准备实体银行卡和现金，但现金币种与数量必须按本次目的地判断。
- 先找出必须或明显更适合使用现金的场景，再估算抵达首日、城市阶段、偏远阶段和应急备用所需金额；不要因“国外旅行”机械兑换大量现金。
- 比较出发前银行换汇、抵达机场、当地银行 / 合法兑换点、ATM 取现和酒店兑换的实际可得性。核验地点、营业时间、证件要求、可兑换币种、ATM 网络、单次 / 单日限额及偏远地区最后可靠取现点。
- 比较总兑换成本：参考汇率、买卖价差、固定手续费、ATM 运营方费用、发卡行境外取现费、货币转换费、最低金额和剩余现金再次兑换损失。
- 单独识别动态货币转换（DCC）或商户代选币种；展示本币结算与用户卡币种结算的差异，并结合发卡行条款给出建议，不让终端默认选项替用户决定。
- 机场或酒店兑换若费用较高但抵达时确有刚需，可以只换足够完成首段交通的小额，再使用成本更合理的主渠道。
- 只推荐银行、持牌兑换点和可靠 ATM；说明假币、街头换汇、吞卡、盗刷与大额现金保管风险。现金分散保存，并规划未用现金的处理方式。
- 区分“普遍可用”和“某些商户可能接受”，不要绝对化银行卡或电子支付覆盖。
- 当地钱包 / App 只有在当地明显便利，且关键场景覆盖、节省的时间 / 费用足以抵消注册、实名、充值和余额退出成本时才推荐；存在可靠国际支付替代时优先通用方案。

## 7. 国际上网与通信

国外旅行把网络视为导航、叫车、购票、翻译、支付和紧急联络的基础条件，不把“到达后再看”作为默认方案。

按本次手机和行程比较：

1. 用户现有中国运营商的国际漫游或流量包；
2. 手机厂商提供的国际上网、虚拟 SIM 或类似服务；
3. 与确切手机型号兼容的旅行 eSIM；
4. 目的地当地实体 SIM / eSIM；
5. 多人共享时可选的随身 Wi-Fi。

必须核验：

- 手机确切型号、销售地区、频段、锁网状态、双卡能力，以及所称服务是标准 eSIM、厂商虚拟通信服务还是普通漫游；不能因为同系列海外版支持 eSIM，就推断中国大陆版也支持；
- 覆盖国家与具体路线、网络制式、速度 / 限速、公平使用政策、热点共享、套餐起算时点、有效天数、续费和税费；
- 是否包含本地号码、普通电话和短信，能否接收交通、银行、住宿或当地 App 验证码；纯数据卡不得写成可收本地短信；
- 当地 SIM 的实名 / 证件要求、官方购买渠道、开卡时间、号码有效期、续费与注销；不索取或记录证件号码；
- 是否能在出发前安装 / 激活、落地后是否需要联网激活、APN / 数据漫游设置和客服渠道；
- 跨境 IP、目的地网络限制和用户所需服务的实际可访问性，并遵守当地法律；
- 手机丢失、套餐失效、信号盲区或电量不足时的第二联络方式。

选择原则：现有漫游或手机厂商方案在覆盖、价格和流量上足够时优先使用；旅行 eSIM 在设备确实兼容且更合适时采用；本地 SIM 在需要本地号码、覆盖明显更好、停留较长或综合成本明显更低时采用。多人随身 Wi-Fi 还要计算设备押金、续航、归还和成员分开行动的影响。

无论主方案是什么，都提前下载离线地图、住宿地址、关键票券、路线和紧急联系方式。偏远徒步、无人区或高风险活动另按 `hiking-rules.md` 评估卫星通信和报备。

## 8. 其他在地使用

- 按本次需要提供电压、插头、常用语言、紧急号码和当地礼仪。

## 9. 交付要求

- 把入境、中转和支付阻断项放在影响预订的位置，而不是埋在攻略末尾。
- 每次国外旅行固定附一张简洁的“国外旅行运行与安全提示卡”，只列本次相关事项：入境 / 口岸、可信来源反复报告的非官方索费风险、账单与小费、支付 / 换汇、交通骗局、重要法律文化规则、紧急求助和临行复核。
- 提示卡中的收费信息使用：`场景｜费用名称｜常见 / 核验金额｜法定 / 强制 / 可选｜通常是否已含｜建议动作｜来源与核验时间`。没有可靠依据时写“尚未查清”，不得编造比例。
- 出境攻略按实际需要增加“换汇与现金方案”和“国际上网方案”：主方案、总成本、启用步骤、适用范围、局限、备份和临行复核。
- 标明核验日期、适用身份和行程条件。
- 日期过远时设置重新核验节点；不能把当前规则保证到未来。
- 法律、医疗和保险信息有疑义时，建议向主管机构或合格专业人士确认。
