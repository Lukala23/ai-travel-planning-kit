# 徒步、登山与户外路线规则

本文件在安全相关事项上覆盖 `route-core.md`。目标是帮助用户判断“是否适合、需要准备什么、怎样进入和退出、何时撤退”，不是替用户制作轨迹或逐路口导航。用户会在自己的徒步软件中下载并管理路线；规划重点是核验可靠路径数据存在，并完善国外徒步的出行、安全与保障条件。

## 目录

- 安全闸门
- 路线数据、关键路径点与用户软件
- 难度、路线卡和折返逻辑
- 国外徒步出行保障
- 装备与临行复核

## 1. 安全闸门

在推荐具体路线前，必须核验：

- 官方开放 / 关闭、许可、配额、施工、火险、狩猎季或保护区限制；
- 路线日期对应的山地 / 局地天气、雷暴、风、降雪、能见度和温差；
- 涉水水位、海岸潮汐、峡谷暴雨、雪崩或落石等地形特定风险；
- 日照长度、建议最晚出发、个人折返点和退出路线；
- 起点交通、停车、末班接驳，以及无车时能否安全返回；
- 用户与同行者中能力最弱者的经验、距离、爬升、技术地形和装备。
- 若在国外：向导 / 旅行社强制要求、路线许可、限制区、保险与救援资格、住宿 / 营地和当地支付能力。

出现以下任一情况时，不给“照常出发”的确定建议：官方关闭；必要许可不可得；严重天气或地质预警；关键路线状态无法核实；难度明显超过用户能力；缺少必需装备或安全返回方案。改给安全替代路线、向导方案或延期条件。

## 2. 可靠路线数据是安全闸门

- 距离、累计爬升、最高点、预计时间、坐标和轨迹必须来自可靠路线资料或实际可验证的地图计算。
- 明确区分单程、往返、环线和含接驳距离；明确海拔高度与累计爬升不是一回事。
- 多来源数值不一致时给范围并解释可能原因，例如轨迹版本、起点或采样精度。
- 不从景点名称、博客描述或几张地图截图猜测路线。出发前必须确认用户能在自己的徒步软件或可信来源中取得对应路线数据，并核对路线名称 / 编号、起终点、版本、更新时间和关键路径点；没有可靠路线或轨迹数据时，判为不建议执行。
- 不默认生成打印地图、GPX 文件或逐路口导航。用户提供已有轨迹并要求核验时，可以检查其元数据、范围和已知冲突，但不能仅凭文件存在就保证当前开放或安全。
- 预计时间优先采用当地官方或成熟路线资料，并结合用户能力校正；公式估算只能标记为估算。

## 3. 关键路径点与用户软件准备

- 至少核验并交付：路线来源或用户软件中的可检索名称 / 编号、起终点、每日住宿 / 营地、关键岔口、垭口 / 最高点、可靠补给与水点、检查站、退出点、接驳点和已知危险段。坐标只取自可信来源，不猜测。
- 使用官方地图 / GPX、保护区或运营机构资料作为第一层；再用可靠商业地图、当地持证向导 / 机构资料和近期轨迹交叉核验。
- 单个游客轨迹只能用于发现问题，不能单独证明当前开放、合法或安全。
- 标明路线数据版本、更新时间、来源、总距离是否包含支线和数据不一致原因；明确用户应在出发前完成离线下载，并在软件中确认关键路径点实际可见。
- 用户的软件是主导航工具，但仍需准备电量 / 充电、离线可用性和至少一种适合本次风险的失效备份；偏远路线按需考虑第二设备、纸质官方图、指北针或合法卫星通信，但不机械要求所有路线携带全部设备。
- 不提供未经核验的“捷径”、越界通道、私人土地路线或已关闭路段。规划正文只说明高层路线结构和安全节点，不抢占篇幅复述用户软件中的逐转向导航。

### 用户下载轨迹后的审核流程

用户可以在自己的徒步软件中选好路线后，提供路线链接 / 编号、导出的 GPX / KML / FIT 等轨迹文件、应用截图或关键路径点清单。审核时：

1. 识别路线来源、名称 / 编号、版本、下载日期、方向和适用季节；来源不明时先保留风险；
2. 读取可用的距离、累计爬升、海拔、起终点和路径点，并与官方 / 保护区资料或成熟路线来源交叉检查；
3. 检查起终点错位、轨迹断裂、异常直线 / 跳点、明显海拔尖峰、错误支线、反向行走影响，以及是否穿过关闭路段、私人土地、限制区或未核验捷径；
4. 核对山屋 / 营地、水源、检查站、垭口、危险段、退出点和接驳是否位于正确路线版本，并检查这些设施的当前状态；
5. 结合当次许可、施工、天气、季节、日照、能力和救援条件，输出 `可用 / 条件可用 / 不建议使用`，列出必须修正或再次确认的项目；
6. 提醒用户在自己的软件中完成离线下载并核对显示，但不替代现场判断，也不把文件审核写成路线绝对安全保证。

文件格式无法读取或路线链接受登录限制时，明确指出审核缺口，并请用户补充可见截图、来源页或路径点数据；不得假装已经审过完整轨迹。

## 4. 难度拆解

不要只写“简单 / 中等 / 困难”。必须分别说明：

- 体能：距离、累计爬升、预计总时长、连续上坡；
- 技术：路面、手脚并用、攀爬、冰雪、涉水、寻路；
- 暴露：陡坎、狭窄山脊、落石、恐高感；
- 环境：海拔、温差、风、日晒、补水点和信号；
- 后果：退出点多少、救援难度、错过接驳的影响。

用 `绿 / 黄 / 红` 做本次条件风险判断：

- `绿`：状态已核验，条件与能力匹配，仍需常规准备；
- `黄`：存在需要临行复核或保守处理的条件，只能条件式出发；
- `红`：当前条件不建议执行，直接给替代方案。

风险颜色必须附理由，不能替代详细数据。

## 5. 路线卡

每条候选路线至少列出：

| 字段 | 内容 |
|---|---|
| 路线类型 | 环线 / 往返 / 穿越；是否需要接驳 |
| 起终点 | 当地可检索名称与可靠定位链接 |
| 距离与爬升 | 数值、范围、数据来源 |
| 海拔 | 起点、最高点；如有关联则说明高反风险 |
| 时间 | 官方 / 来源时间、按用户能力的预计总时间、缓冲 |
| 地形与难点 | 最困难一段、暴露、涉水、积雪或寻路 |
| 路径数据 | 可靠路线 / 轨迹来源、名称或编号、更新时间及用户软件离线下载状态 |
| 退出与折返点 | 明确位置、最晚折返时间和失败后的回程 |
| 补给 | 可靠水源、厕所、避难设施；季节性设施要核验 |
| 通信与救援 | 信号预期、当地应急号码、登记 / 报备方式 |
| 许可与限制 | 预约、费用、宠物、露营、火源、无人机等 |
| 支付与现金 | 门票、住宿、餐食、充电、向导和撤离所需支付方式与现金窗口 |
| 当前风险 | 绿 / 黄 / 红及依据 |

## 6. 高层路线结构与折返逻辑

- 只按安全和日程需要概括各段距离、爬升、典型耗时、关键岔口与危险点，不复述用户徒步软件能够提供的逐路口导航，也不用城市行程的“景点打卡表”代替。
- 设定个人折返时间：根据日落、天气窗口、下撤速度、接驳和最弱成员计算。
- 任何成员达到预设不适、天气恶化、路线不明或进度落后条件时，执行折返，不以“离终点不远”为理由继续。
- 穿越路线必须有接驳失败方案；涉水路线必须有水位过高的退出方案。

## 7. 国外徒步专项检查

国外徒步不能套用国内线路信息完整度、救援方式和支付习惯。路线几何由用户在自己的软件中处理；攻略篇幅优先用于进出交通、合法性、安全、保险、医疗、住宿、食物饮水、通信、支付、装备和应急。按本次国家与路线逐项核验：

本节只补充“路线特定”的海拔、活动、搜救和偏远医疗条件。一般旅行健康、药品与就医规划执行 `health-and-medical.md`；整份保单与保障缺口执行 `travel-insurance.md`，再把本路线的活动定义、最高海拔和搜救方式带回保单逐项核对。

### 许可、向导和路线合法性

- 国家 / 地区许可、国家公园费、地方费、限制区许可、检查站和每日登记；
- 是否强制持证向导、注册旅行社、规定队伍人数或指定口岸进出；
- 许可由谁申请、需要多久、原件 / 电子件、照片、现金或线上支付，以及节假日办公影响；
- 不同官方机构规则冲突时保留冲突，并在出发前向主管机构或注册机构确认。

尼泊尔等目的地必须在规划当次重新核验 TIMS、限制区许可和持证向导要求；不要用过去年份或其他山谷的规则代替。

### 海拔、健康与日程

- 列出每天起点、最高点和睡眠海拔，以及睡眠海拔日增幅和适应日；
- 高海拔风险按进入海拔、上升速度和既往反应评估，不能用“平时体能好”推断不高反；
- 写出不再上升、必须下降和呼叫救援的症状阈值，但不远程诊断或替用户开药；
- 核验起终点及途中可用医疗点、最近有能力处理相关问题的医疗机构、转运方式、预计到达难度和紧急联系方式；偏远地区不能只写城市医院名称。
- 对既往疾病、用药、疫苗、高反预防、腹泻与饮水风险建议用户在出发前咨询旅行医学或合格医生；同时核验处方药、急救药品和医疗设备的入境 / 航空限制，不替用户开药。

### 保险、救援与通信

- 核验保单是否覆盖具体活动、最高海拔、徒步 / 登山定义、直升机 / 地面搜救、医疗和遗体运送；
- 核验救援是否需要预授权、先垫付、联系指定公司，以及当地实际报警 / 救援流程；
- 提供当地 SIM / eSIM 覆盖预期、离线地图、住宿 Wi-Fi、充电和停电风险；
- 偏远、无信号或单人路线按当地法律与实际需要评估卫星通信 / 定位设备，并核验其合法性。

### 住宿、食物、饮水和现金

- 核验山屋、茶屋、营地的营业季、预约方式、床位、供暖、洗浴、充电、网络和被褥条件；
- 说明餐食供应、特殊饮食可行性、饮水来源与净化方案，不把地图水点当作保证；
- 说明卫生间 / 洗浴、床品、低温、虫害或高海拔睡眠等会影响恢复的现实条件，并给必要自备物品；
- 标出最后可靠 ATM / 换汇 / 刷卡点和之后所需现金区间，现金分散保存；
- 检查停电、无网、二维码失效或外卡拒付后的备份。

### 向导、背夫和当地机构

- 法律强制时必须使用符合要求的注册机构或持证向导；非强制时，不因“国外”自动推荐或排除，而是比较自助、向导、向导 + 背夫在路线熟悉、语言、许可办理、住宿协调、负重、天气判断、急救 / 通信和救援联络上的真实增益，由用户结合当次能力与风险选择；
- 核验旅行社注册、向导证照、责任范围、保险、费用包含项、取消和救援处理；按确切路线、日期、人数、天数和服务模式给当地货币价格与人民币约值；
- 说明背夫负重、住宿、装备、保险和小费惯例，优先选择有明确劳动保障的机构；
- 不以社交媒体粉丝量代替资质，不接受通过虚假伤情或不透明佣金安排救援。

### 季节、交通和环境

- 检查季风、降雪、垭口、山火、落石、雪崩、航班 / 吉普取消和道路中断；
- 为高风险进出交通保留天气机动日，不把山区航班或车辆到达写成确定承诺；
- 核验垃圾、人类排泄物、燃料、露营、火源、野生动物和文化 / 宗教场所规则；
- 说明海关、行李和航空公司对燃料、气罐、电池、登山杖、卫星设备和药品的限制。

## 8. 装备与临行复核

装备清单必须匹配路线、季节和当地规则，分为：必需、条件必需、可选。不要用通用“户外十大件”替代路线判断。

- 核验当地购买、租借、燃料补给、维修和更换关键装备的地点、价格与营业季；偏远段之前标出最后可靠补给点。
- 结合住宿供暖 / 被褥、降水、温差、紫外线、泥雪、涉水、海拔、充电和行李运输条件决定服装、鞋袜、防水、保温、照明、电源、净水和急救用品；不因为山屋提供某项服务就假定无需备份。

临行复核至少包含：

- `T-7 天`：许可、交通、路线关闭和大尺度天气；
- `T-48 小时`：局地天气、雷暴 / 风 / 雪 / 水位 / 潮汐；
- `出发前`：官方告示、接驳、装备、离线地图、电量、饮水与行程报备；
- `起点`：现场封闭、能见度、队伍状态和最晚折返时间。

医疗、营养和高反问题只提供通用风险提醒，并建议按个人情况咨询合格专业人士；不得假装远程诊断。

## 9. 国外徒步交付重点

国外徒步优先交付一张执行卡：

| 模块 | 必须给出的结论 |
|---|---|
| 路径数据 | 可靠路线 / 轨迹是否存在、名称 / 编号、来源与关键路径点是否可在用户软件中离线取得 |
| 进出交通 | 起点、终点、接驳、行李、取消风险与天气机动日 |
| 许可与向导 | 当前法律要求、办理方法，以及自助 / 向导 / 背夫的条件式比较与价格 |
| 保险与救援 | 活动 / 海拔覆盖、搜救与医疗转运、预授权 / 垫付、实际联络流程 |
| 医疗与海拔 | 适应安排、停止上升 / 下降条件、医疗点与旅行医学准备 |
| 住宿与恢复 | 山屋 / 营地的预订、供暖、床品、卫生、充电和网络 |
| 食物与饮水 | 供应、饮食限制、可靠水源、净化和食品卫生风险 |
| 通信与电力 | SIM / Wi-Fi 覆盖、离线信息、电量、失联与卫星通信条件 |
| 现金与支付 | 最后 ATM / 换汇点、必付费用、现金区间与分散保管 |
| 装备 | 路线特定必需 / 条件必需项目、租借维修与运输限制 |
| 安全与放弃条件 | 天气、关闭、折返、退出、报备、紧急号码和最终 `可行 / 条件可行 / 不建议` |

除非用户另行要求核验已有轨迹，否则不把攻略篇幅用于生成地图、GPX 或详细逐段导航。
