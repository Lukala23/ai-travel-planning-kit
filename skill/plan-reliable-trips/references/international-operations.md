# 境外支付、通信与在地运行规则

仅在当前问题需要境外支付、换汇、通信、账单、小费、法律文化或实际运行方案，或一条可执行的境外路线必须依赖这些信息时读取。窄的签证 / 中转问题不加载本模块。

出入境合法性由 `entry-and-transit.md` 负责；公共交通的具体票制由 `public-transit.md` 负责。本文件只解决抵达后“怎样可靠使用这趟旅行”。

## 1. 支付方式按本次覆盖与可靠性选择

现金、实体银行卡和数字钱包都是候选。对从中国出发的用户，先核验已经配置且能跨地区复用的数字钱包或手机非接触支付，例如支付宝、微信支付、Apple Pay、Google Wallet / Google Pay；再与实体银行卡和现金按本次实际受理范围、完整费用、设置成本、网络 / 电量依赖和失败后果并列比较。数字钱包优先只是便利倾向，不是绝对结论。

不得因为钱包、银联、Visa、Mastercard 等标志在当地出现，就保证用户账户可用。按需核验：

- 用户侧：手机系统、NFC、地区、App、绑定卡 / 余额和境外资格；
- 受理侧：具体商户、运营商、票种和支付场景；
- 结算侧：币种、汇率、手续费、预授权、限额和退款；
- 行程侧：是否提前激活、是否依赖网络、多人使用和故障恢复。

目的地专用钱包或 App 只有在关键场景特别实用，或者没有它会造成明显不便、价格损失或无法使用重要服务，且收益足以抵消注册、实名、本地号码、绑卡 / 充值、语言、退款和余额退出成本时才推荐。存在同等可靠的通用方案时不为形式增加账户。

## 2. 现金、换汇与独立备份

- 找出必须或明显更适合现金的场景，再估算抵达首日、日常、偏远阶段和应急金额；不因“出国”机械兑换大量现金。
- 比较出发前银行、机场、当地银行 / 持牌兑换点和可靠 ATM 的实际可得性与总成本：价差、固定费、ATM 运营方费、发卡行取现 / 转换费、限额和剩余现金损失。
- 单独识别动态货币转换（DCC）；刷卡或取现前核对终端币种，不让商户默认选项替用户决定。
- 主支付和备份不得依赖同一部手机、同一张卡或同一账户。至少准备一种独立实体备份，并写明失电、风控、短信失败、拒付或吞卡后的动作。
- 只推荐银行、持牌兑换点和可靠 ATM；说明街头换汇、假币、盗刷和大额现金保管风险。

## 3. 国际上网与通信

按本次手机和路线比较：中国运营商国际漫游 / 流量包、手机厂商服务、旅行 eSIM、目的地实体 SIM / eSIM，以及多人需要时的随身 Wi-Fi。

只核验会改变选择的字段：

- 确切手机型号、销售地区、频段、锁网、双卡和 eSIM 能力；不能用同系列海外版推断中国大陆版；
- 覆盖路线、网络、限速 / 公平使用、热点、起算时点、有效期、续费、税费；
- 是否含本地号码、电话和短信，能否接收必要验证码；纯数据卡不能写成可收本地短信；
- 本地 SIM 的实名要求、官方渠道、开卡、续费 / 注销和是否需要本地支付；不索取证件号码；
- 出发前安装、落地激活、APN / 数据漫游、客服，以及丢机、失效、无信号或无电时的第二联络方式。

现有漫游在覆盖、价格和流量上足够时可以直接采用；eSIM 只在设备兼容时采用；需要本地号码、覆盖明显更好、停留较长或总成本显著更低时再选本地 SIM。无论主方案为何，都离线保存地图、住宿地址、票券、路线和紧急联系方式。

## 4. 税费、小费与账单

只研究本次会遇到的场景，并把以下项目分开：

- 法定增值税、销售税或消费税；
- 强制服务费、城市 / 旅游 / 住宿税、度假费；
- 餐位、面包 / 饮水、最低消费、清洁或平台附加费；
- 银行卡、外币、ATM 或预订费；
- 可退押金 / 预授权；
- 顾客自主决定的可选小费。

说明费用名称、金额或比例、强制 / 可选、是否通常含在标价、由谁收取、支付与收据方式。法规、行业惯例和近期旅客经验分开标记；不能用一个国家或城市推断邻国和所有商户。

遇到不明收费时：索取逐项账单，确认费用名称与强制性，对照菜单 / 预订条款，核对终端金额和币种，必要时请经理或平台解释并保留凭证。已含服务费时避免无意重复给小费。不把拒付或现场冲突设为统一答案；人身与证件安全优先。

## 5. 法律、文化与实际运行

只覆盖会改变本次行为或路线的内容：

- 周末、宗教日、午休、罢工、节庆与预约习惯；
- 携带证件、住宿登记、实名票和安检要求；
- 着装、宗教、饮酒、公共礼仪、摄影和性别相关规则；
- 合法叫车点、持牌出租车、常见骗局、临时加价和现金找零；重要接送或议价场景转交 `taxi-charter.md`；
- 本次需要的电压、插头、语言、紧急号码和使领馆 / 领事保护入口。

低后果在地习惯可用可信近期资料作规划判断；法律、强制收费和安全事项按高后果规则核验。

## 6. 输出边界

只输出当前需要的支付、换汇、通信或在地提醒。对完整境外路线，可以附一张精简运行卡：`场景｜主方案｜备份｜费用 / 条件｜失败动作｜来源与复查日`。窄问题不固定生成安全卡、换汇章、上网章或大清单。
