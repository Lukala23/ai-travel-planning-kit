# 旅行摄影、常规景点拍法与参考图规则

路线轻量扫描发现拍摄机会，或用户明确重视摄影时读取。用户长期默认使用手机，最多增加 Osmo Pocket 等随身便携设备；不要每次追问器材，也不要把摄影建议建立在专业相机和镜头上。重点是构图、站位、光线、人物关系与审美判断。

## 1. 独立判断摄影与社交发布价值

不得按“网红、点赞多、打卡人数多”直接判定必拍。综合判断：

- 题材是否具有当地辨识度和不可替代性；
- 空间、前中后景、尺度、线条、色彩或人物活动是否能形成完整画面；
- 是否依赖特定光线、天气、季节、水位或人流；
- 是否有合法公开、能够稳定复现的拍摄位置；
- 为这个画面付出的早起、绕行、等待、体力和安全返回成本是否值得；
- 网络照片是否只是重度修图、无人机、长焦压缩或非公开机位造成的错觉。

使用官方图片、地图 / 卫星图、太阳路径和不同来源的近期实景图交叉判断；热度只用于判断拥挤，不作为价值评分。

社交发布价值看画面本身，而不是平台热度：地点特征是否清楚，单张或组图是否有主体、环境、细节和人物尺度，能否形成真实旅行叙事，以及普通游客能否在公开位置和便携设备条件下复现。容易造成危险示范、文化冒犯、隐私侵害或脆弱地点过度暴露时，降低推荐或不提供精确点位。

某地点同时具有重大摄影价值和重大社交发布价值，且新增时间、交通、费用、体力、安全、拥挤与同行者成本可控时，提高路线优先级。早起是用户可接受的选项；只有地点真正值得，且睡眠、交通、天气和安全返回可合理处理时才安排。长时间等待、明显绕行或需要牺牲其他核心体验时，不自动写进主路线，另给拍摄强化方案。

## 2. 常规景点也提供实用拍法

不能只研究少数“摄影圣地”。对正式路线中的核心景点和大众常去地点都做拍摄可用性扫描：

- 有明确可复现的好构图时，即使不值得为摄影改路线，也给一句到数句可执行建议：在哪里站、朝哪里拍、画面保留什么、避开什么，以及人物放在哪里；
- 画面依赖某个入口、台阶、拐角、桥面、倒影、框景或建筑轴线时，给可检索的现场定位，避免只写“找好角度”；
- 人流密集时说明通过拍摄时段、机位高度、等待短暂空隙、裁切或改变朝向减少杂乱的方法，不承诺无人画面；
- 旅行价值很高但摄影表现普通时，可写 `记录即可` 并给最稳妥的纪念照方法，不硬造“大片机位”。

统一使用：

- `必拍`：画面价值明确且难替代，值得围绕时段安排；
- `值得拍`：顺路或条件合适时值得停留；
- `记录即可`：不为摄影增加成本，但给实用记录建议；
- `不建议专程拍`：画面收益不足或成本、限制、风险不成比例。

整条路线都要扫描，详细点位卡只给 `必拍` 和重要的 `值得拍`；普通地点用短建议，避免摄影信息淹没攻略。

## 3. 手机与便携设备优先的构图建议

- 优先说明观察与移动：主体取舍、横竖构图、画面边缘、地平线、对称 / 非对称、前中后景、引导线、框景、留白、人物尺度和背景清理。
- 把建议翻译成现场动作，例如前进或后退几米、降低或提高机位、把人物放在建筑轴线外、等待一辆车或一组人经过，而不是堆摄影术语。
- 只有确实影响成片时才提示常见手机的广角 / 标准 / 近摄选择、曝光锁定、夜景稳定或 Osmo Pocket 的稳定移动；不默认拥有专业长焦、滤镜或三脚架。
- 不建议用超广角无目的地塞满画面，也不让器材差异掩盖构图、光线和时机问题。
- 用户当次明确带相机或其他设备时再补充针对性设置；器材不作为每次出行的必填项。

## 4. 重点拍摄点卡片

对 `必拍` 和重要的 `值得拍` 点至少给出：

| 字段 | 要求 |
|---|---|
| 点位 | 可公开到达的准确位置、入口或可靠地图定位；不猜坐标 |
| 主体与画面价值 | 拍什么，地方辨识度和画面叙事是什么；不引用热度代替判断 |
| 站位与朝向 | 从哪里面向哪里，前景、层次、人物位置与需要避开的杂乱元素 |
| 最佳条件 | 具体日期下的光线窗口、太阳方向、天气、季节和人流 |
| 手机拍法 | 横竖构图、机位高度、常用视角、曝光 / 稳定提醒；器材不是硬要求 |
| 时间成本 | 早起、步行、短等候、长等待和转场各需要多少 |
| 限制与礼仪 | 闪光灯、三脚架、无人机、商业拍摄、宗教和私人空间规则 |
| 失败备选 | 光线、天气、人流或封闭不合适时的替代位置 / 题材 |
| 参考图片 | 可见预览、原始来源与这张图值得借鉴的构图要点 |

## 5. 必须提供实际参考图片

实际参考图用于让用户看懂站位、层次、人物比例和光线效果，不能只用文字替代。

- `必拍` 和重要的 `值得拍` 默认提供 1–3 张有明确用途的参考图；常规知名景点若文字不足以解释构图，也至少提供一张代表性参考图或紧凑图片组。
- 优先使用目的地 / 景点官方页面、文化机构、旅游局、可追溯的原作者页面、Wikimedia Commons 等有清楚来源的图片；地图和社交图片可用于现场交叉检查，但不以单张网红图证明可复现性。
- 在交付中展示实际可见的图片预览，并同时附原始来源页面、作者 / 机构（可获得时）和查证日期；不把搜索结果页或无来源转载图作为引用。若来源或技术条件不允许内嵌，明确说明并提供可直接打开的原图 / 来源页，不静默改成纯文字。
- 每张参考图写清 `借鉴什么`：站位、朝向、前景、人物位置、画面比例或光线；也写明 `不要误以为` 的部分，例如无人机、长焦压缩、重度后期、特殊季节或封路清场。
- 参考图是构图与条件示例，不保证届时天气、云量、倒影、花期、人流或颜色完全相同；日期、太阳方向和现场开放仍需按本次核验。
- 不为了增加图片数量重复相同机位；同一地点优先展示能说明不同构图选择或条件差异的少量图片。

## 6. 把摄影写进路线

- 按实际日期和地点计算日出、日落、蓝调和太阳方向；日期未知时只给季节方向，不给虚假精确时间。
- 先确定最依赖光线的少数锚点，再安排其他景点，避免所有地点都争夺同一个黄金时段。
- 把早起、架机位、等待、人流、器材寄存和转场计入停留时间；早起虽然可接受，也必须说明起床 / 出发时间与对当日后续体力的影响。
- 标出景点之间、交通途中、桥上、步道或街区中的高价值沿途拍摄点，并计入停留和安全位置。
- 日出前、日落后或偏远机位必须有可执行的交通、照明与安全返回方案。
- 顺路且新增成本可控的高价值机会直接整合；长时间等待、明显绕行或挤占其他核心体验时，并列给 `普通游览方案` 与 `拍摄强化方案`，由用户决定。

## 7. 合法、安全和真实

- 不引导翻越、闯入私人区域、站在车道、铁路、悬崖边或阻碍通行。
- 核验闪光灯、三脚架、无人机、肖像权、儿童、宗教仪式和商业拍摄规定。
- 不保证天气、云量、倒影、花期或无人画面；说明成功条件和临行复核时间。
- 不照搬他人照片或构图文案；参考图用于分析，最终建议必须结合本次日期、路线和公开可达条件独立判断。
