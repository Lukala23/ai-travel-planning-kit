# 出入境、国际中转与口岸规则

仅在当前问题需要判断签证、入境、国际中转、海关或口岸文件，或这些未决事项会实质阻断当前方案时读取。国外目的地只是背景时不自动加载。

本模块负责“能否合法完成这段跨境行程”。机票路线、价格和舒适度由 `air-travel.md` 负责；境外支付、通信和日常运行由 `international-operations.md` 负责。平台能售票不等于旅客有权过境或入境。

## 1. 先锁定适用对象与完整链路

只提取判断当前问题必需的信息：

- 护照或旅行证件的签发国家 / 地区，必要时再确认居留身份；
- 出发地、中转国家与机场、目的地、停留时长和旅行目的；
- 是否同一张受保护联程票、是否行李直挂、是否换航站楼 / 机场、是否需过夜或离开国际区；
- 准确旅行日期，以及会改变规则的同行人类别。

不索取护照号、身份证号、详细住址、银行卡、验证码或未脱敏证件图片。不能把其他国籍、其他机场、其他口岸或往年规则套用给用户。

## 2. 反向列出最低可行要求

不要先笼统判断“可行 / 不可行”，先按当前链路列出必须满足的项目，再判断状态：

- 签证、免签、电子许可、过境签、入境卡、停留期限；
- 护照有效期、空白页、返程 / 联程票、住宿、资金或邀请材料；
- 国际中转是否全程空侧，是否必须入境、提取并重新托运行李、换机场或重新安检；
- 海关、检疫、药品、食品、现金申报、电池、无人机及其他本次携带物限制；
- 登机或入境强制要求的保险证明、健康申报、疫苗证书或药品文件；
- 官方费用、办理入口、处理时长、节假日和最晚可行动日期。

每项使用 `已满足 / 待确认 / 不满足 / 不适用`，最后给 `可行 / 条件可行 / 明显不满足 / 尚无法判断`。没有发现明显阻断时，仍保留尚待办理和临行复核项；不要把“目前未发现问题”写成入境保证。

## 3. 核验方法

- 至少使用一个对本次证件和路线负责的主管机构或实际运营方直接来源。
- 当原文含糊、来源冲突、页面无法访问，或错误后果严重且实际可行时，再用第二个独立来源交叉检查；多个转载同一原文不算独立。
- 优先级通常为：目的地 / 中转地移民、使领馆或领事服务、海关、机场、实际承运航空公司。
- 核对发布日期、适用日期、旅客身份、机场 / 口岸、航站楼、票制和行李条件。航空公司或第三方数据库可以辅助登机执行，不能覆盖主管机关的法律规则。
- 日期较远时明确当前查证日和重新核验节点；无法访问动态页面时给出官方入口与待确认问题，不凭记忆补答案。

## 4. 通关准备与官方收费

- 只检查本次需要的电子签 / ETA、入境卡、海关或健康申报、预登记、在线值机和证件预审。
- 把签证 / 落地许可、边检、检疫、海关、提取行李、重新托运和航站楼移动分别计算。
- 官方费用必须核验收费名称、金额、适用对象、官方渠道和收据；不得把商业快速通道写成能保证入境、跳过海关或获得公职人员特殊照顾。
- 付费快速通道或礼宾只在用户询问，或紧张转机 / 行动协助确有价值时研究，并写清覆盖环节。

## 5. 携带物与购买品的海关合法性

纪念品、伴手礼与购物的挑选本身按普通偏好直接建议（优先有当地辨识度、有趣、便携、价格合适的物品，不默认推荐昂贵收藏品）；本模块只负责其中的合法性问题：

- 不推荐、不默认纳入行程的购买项：疑似盗掘文物、假古董或来源不明的"古物"；象牙、珊瑚、玳瑁、贝壳制品、皮草、濒危动植物及其制品等受 CITES 或双边检疫管制的物品；当地明确禁止出口的传统药物、矿石或宗教文物。
- 出境与入境两侧都要看：液体、酒类、肉制品、奶制品、种子、水果、药品（尤其含管制成分的复方药）既要符合目的地入境规则，也要能合法带回本国；仅写"当地能买"不算完成核验。
- 议价与退换是商业习惯问题：只在当地确属常规时提示，不把"必须砍价"写成规则。
- 无法确认合法性的物品，明确标注"无法确认，出发前向海关或官方渠道核实"，不给含糊的"应该没问题"。

## 6. 非官方索费与证件安全

只有官方旅行提示或多个可信近期来源反复指出特定口岸、流程或人群存在风险时才预警，不能用个别帖子给整个国家贴标签。

- 分开列明已核验官方费用与被报告的非官方索要；不建议、暗示或常态化向公职人员付款。
- 安全可行时，礼貌询问收费名称与官方依据，使用正式窗口 / 电子渠道，索取收据或请求值班主管。
- 不鼓励争吵、肢体对抗或违法偷拍。人身和证件安全优先；离开危险后按当地方式联系口岸运营方、旅游警察、使领馆或领事保护，并保留合法取得的时间地点与凭证。

## 7. 国际中转与抵达执行

- 使用完整当地日期、星期、时区、机场和航站楼；跨日期变更线时明确抵达日。
- 分开计算值机、安检、边检、行李提取 / 重托、航站楼 / 机场转移和再次登机。
- 不把航空公司最短转机时间当作用户必然赶得上的保证；识别受保护联程与自行转机责任。
- 若当前问题包含抵达后的首段衔接，再核验末班交通、深夜住宿 / 接驳和错过后的可执行方案；否则不要扩展成完整在地运行攻略。

## 8. 最小交付

窄问题使用：`结论 → 决定结论的条件 → 尚缺信息 → 最低可行要求 → 来源与复查日`。只回答当前签证、入境或中转问题，不顺带展开机票、住宿、支付、保险产品或全程路线。
