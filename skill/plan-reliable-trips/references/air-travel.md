# 航空交通、机票搜索与购买策略

仅在当前请求需要设计、比较、复核或制定跟踪策略的航空链路，或未订航班会实质阻断当前路线 / 成本时读取。旅行背景中“机票尚未买”本身不触发。目的地国境内航班也由本模块负责。

本模块负责航线、票价、舒适度、衔接风险和购买策略。`entry-and-transit.md` 负责入境与国际中转是否合法；`public-transit.md` 负责铁路、轮渡、机场公共接驳和在地公共交通。

## 1. 固定当前比较口径

从本次任务提取，已明确的不重复询问：

- 中国境内实际出发城市 / 可接受机场范围、首个旅行节点、最后旅行节点、最终返回地，以及需要航空连接的中间节点；不需要家庭地址；
- 完整日期、弹性、人数和影响票价的年龄类别；
- 舱等、托运 / 手提行李、选座和行李直挂需求；
- 可接受的转机次数、门到门时长、红眼 / 过夜、跨机场、自行转机和分开出票风险；
- 是否接受先乘高铁或国内航班到其他中国出境口岸，以及必要前置住宿；
- 预算、退改弹性和必须到达时间；里程、会籍或指定航司只在本次相关时纳入。

日期或人数未确定时，只比较航线结构、弹性日期和搜索方法，不把示例价写成可购买报价。

## 2. 从实际出发地比较完整往返链路

先比较 `实际出发地 → 首个旅行节点` 与 `最后旅行节点 → 实际返回地` 的直达、一次中转和受保护联程；路线适合时再比较开口程或多城市票。

只有实际出发地方案明显不理想时，才根据当次航线与价格增加其他中国枢纽，不固定假设某几个大城市一定更优。每个前置到枢纽的方案都计入：

- 国内航班或铁路、车站 / 机场转换、必要住宿和餐食；
- 两段行李、提取 / 重托、值机、安检和跨机场；
- 是否由一张受保护联程客票覆盖、错过后由谁负责，以及入境 / 过境文件；同一平台订单号不能证明受到保护；
- 前置段延误、红眼、长等待、完整门到门时间和体力成本。

只有完整成本、时间和风险综合后确实更优，才推荐“先到其他城市再飞”。分开出票必须作为风险不同的独立候选。

## 3. 目的地国境内航空段

目的地境内跨越远距离、岛屿或地面交通薄弱区域时，把航班作为正式城际候选，但按门到门而不是飞行时间比较：

- 本模块研究航班、票价、行李、退改和衔接；`public-transit.md` 研究铁路、长途车、轮渡和机场地面接驳；
- 优先核验目的地机场、实际承运 / 出票航司和当地有效销售渠道；中国平台只在用户能购买且价格或售后有优势时补充；
- 计入税费、廉航行李 / 选座、机场接驳、值机安检、班次密度、取消后的下一方案和被迫住宿；
- 与国际段同日衔接时，核验受保护联程、入境、行李重托、航站楼转换和自行转机缓冲；
- 把航班时刻接入当天住宿、活动和机场交通，不能把它当作孤立段落。

## 4. 中国市场搜索与最终复价

从中国出发的国际往返及可在中国购买的航段，优先使用用户实际可访问和购买的中国市场渠道，如携程、去哪儿、飞猪，再用航司直接渠道核验最终候选。按需要用全球元搜索或目的地当地渠道补充灵活日期、附近机场和境外航段；任何单一渠道都不能证明覆盖全部票价。

仅在页面可访问且口径清楚时使用低价日历、价格趋势和降价提醒。最终比较必须保持相同乘客、日期、舱等、行李和币种，尽量复价到订单确认前，并识别会员、优惠券、App、补贴或支付条件。

无法访问登录后或强动态页面时，不编造当前价格。改为：

1. 给出可直接复制的出发地、目的地、日期、舱等和行李搜索组合；
2. 列明应在中国平台和航司渠道分别记录的字段；
3. 请用户提供去敏后的报价 / 截图，再按同一口径比较。

## 5. 归一完整成本、时间与责任

每个候选按需核对：

- 含税票价、行李、选座、支付 / 平台费和必要证件成本；
- 前置交通、跨机场、机场接驳、住宿与衍生餐食；
- 完整日期、时区、航站楼、过夜和门到门时间；
- 实际承运航司、票价产品、舱等；机型 / 座椅只作为可变信息；
- 联程保护、出票 / 承运责任、行李直挂、自行转机、重托和实际缓冲；
- 退票、改签、误机、变动保护、售后责任和出票渠道。

最低票面价不自动成为推荐。综合价格、总时长、睡眠损失、出发 / 抵达时刻、行李、衔接保护和售后可执行性，并接入行程首末日。

## 6. 购买时机与跟踪协议

不存在适用于所有航线的固定“提前多少天最便宜”。优先依据本次航线、日期和中国销售市场的当前证据：同口径现价、可访问的低价日历 / 趋势提示、用户记录的价格快照、节假日与事件、日期刚性、可替代航班和退改成本。其他市场统计只能注明样本范围后作背景。

给出 `建议现在购买 / 设置提醒并观察 / 等待条件明确 / 尚无法判断`，并解释票价与行程风险。

若观察，提供可手动执行的跟踪协议：确切搜索组合、平台、当前完整价格与时间、目标价或可接受区间、触发购买条件，以及不再等待的最晚决策日。价格、理想航班或条款恶化时写明动作。没有路线级历史数据时坦诚无法可靠推断趋势。

除非当前宿主确有定时与持久化能力且用户明确授权，否则不声称会持续查询或主动通知；提醒触发后仍需在最终订单页复价。

## 7. 交付与动作边界

只保留真正有差异的候选，通常最多为 `综合推荐 / 最低完整成本 / 更舒适或低风险`，不存在差异时不凑数。

| 方案 | 完整航空链路 | 完整价格与时间 | 行李 / 票价产品 | 中转与保护 | 舒适度 | 退改与售后 | 衍生成本 / 风险 | 来源与时间 |
|---|---|---|---|---|---|---|---|---|

表后给出选择、购买时机和下一步。未经明确授权，不登录、使用积分、填写旅客证件、下单或支付；截图和输出不得暴露订单号、证件号、手机号、常旅客号或支付信息。
