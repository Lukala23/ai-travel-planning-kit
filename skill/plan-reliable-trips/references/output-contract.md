# 攻略交付组件与质量检查

除“结论先行”和“动态事实有来源”外，不强制所有攻略采用同一章节顺序。根据单次任务卡只组合相关组件。

## 目录

- 所有任务的共同交付
- 通用表达
- 按任务选择组件
- 最终质量检查

## 1. 所有任务都必须包含

- **结论**：可行性、推荐骨架、最关键取舍和最大风险；
- **本次输入摘要**：使用了哪些单次参数，哪些未知，哪些为显式假设；
- **核心结果**：候选、路线、比较或更新结果；
- **尚未确定的内容**：仍需查清、出发前要复查和会改变方案的条件；
- **证据**：动态结论附近的直接来源和核验日期。
- **摄影建议（按需）**：存在真正有价值的拍摄机会时，写入相应路线节点；没有则不单列。

不要先写目的地宣传文案。

## 2. 通用表达规则

- 中国以外地点首次出现时写“中文名（当地语言或官方英文名）”，后续使用一致中文名。
- 当地名称必须能在主流地图或官方网站检索。
- 写完整日期、星期、当地时间与时区；相对日期有歧义时明确说明。
- 区分事实、估算、推断和建议。
- 使用“必须预约 / 强烈建议预约 / 可现场决定 / 尚未查清”的统一词汇。
- 不输出与本次方式无关的章节。

## 3. 按任务选择组件

### 目的地探索或候选全集

可组合：研究边界、空间分区、交通枢纽、A / B / C 候选、必要的 D 级排除说明、便利摩擦、预约与季节、不同天数的路线骨架、关键取舍。

### 普通路线

需要逐时计划时使用：

| 当地时间 | 节点与体验重点 | 交通 / 步行 | 停留与缓冲 | 预约 / 最晚时间 | 信息确认情况与来源 |
|---|---|---|---|---|---|

按需增加：路线逻辑、每日强度、住宿基点与周边生活、交通与预订、费用、在地饮食、天气、摄影、缩短方案、回住宿 / 枢纽方案。

普通观光旅行未另行说明时采用平衡观光模式，并用每日预计起止、核心体验块、步行 / 站立量、硬预约和优先删减点说明具体强度。明确度假或高覆盖时再切换，不能仅输出“松弛 / 平衡 / 紧凑”而不解释。

### 比较任务

先写选择标准，再用同一组维度比较。至少包含：适用条件、时间、费用、便利摩擦、主要风险、不可逆代价和推荐结论。不要把不同口径的价格或耗时放在一起比较。

### 出境或跨境

按需增加：入境与中转、正常通关准备、可信来源反复报告的口岸非官方索费风险、当地交通、换汇与现金、货币支付、税 / 服务费 / 小费、国际上网、时区、保险、当地法规和紧急信息。只写与本次证件签发地、手机条件及行程相关的内容。

机场 / 航空公司的付费快速通道或礼宾不是默认必查项；只有用户询问或本次有明确需求时才研究，并区分值机、安检、行李、引导与移民 / 海关流程，不暗示付费服务能保证边检准入或特殊照顾。每次国外旅行固定附一张简洁的“国外旅行运行与安全提示卡”，只保留本次相关的规则、实际惯例、收费、风险、应对和复核节点。

### 住宿与住宿区域

过夜旅行必须主动形成住宿结论。需要选住宿时先比较区域，再从住宿官方渠道、Trip.com、Booking.com 和目的地适用平台中搜索高匹配候选，统一日期、人数、房型、取消和税费口径。交付具体住宿、全程真实总价、路线与周边步行、在地餐饮、房型权益、取消付款、风险、查询渠道和时间；法定税、城市 / 旅游税、服务 / 度假 / 清洁 / 平台费、自愿小费和押金 / 预授权分别说明，不能用一个“税费”总数掩盖到店支出。体验型住宿单独说明独特价值、精确房型 / 景观条件、换住成本和天气失败风险。住宿已订时核验适配性和路线影响。

### 在地饮食与餐厅

跨越正餐的路线必须给可执行用餐安排。先概括本次值得体验的当地饮食，再把高价值餐厅、小店、市场或适合现场选择的餐饮区域排入每日路线。具体推荐包含招牌菜、在地价值、人均、法定税 / 强制服务费 / 其他附加费 / 自愿小费、营业 / 预约 / 排队、绕行、支付、饮食限制、主备选和来源；不得仅凭小红书、Google Maps 分数或“网红 / 本地人最爱”标签下结论。

### 公共交通支付

涉及公共交通时给出：票制、主支付、用户侧设置、具体运营商受理、手续费 / 汇率、是否需同一媒介进出站、实体备份和支付失败处理。

### 出租车、接送机、包车与特殊交通

重要路段必须给：确切起终点和时段、首选正规渠道、当地货币价格区间与人民币约值、价格依据及核验日期、包含 / 另付项目、App 或书面确认方法、当地语言总价话术、常见异常、失败备选和已核验求助入口。马车、骑乘、突突车、摩托车、传统船只等再说明按人 / 车 / 船 / 时间 / 圈数的计价单位、路线与结束点、安全装备、天气 / 水况及动物福利。无法取得可靠价格时不得猜测。

### 换汇、现金与国际上网

国外旅行按需给出：现金使用场景与合理区间、换汇 / ATM 渠道、全部费用和抵达首段方案；以及漫游、手机厂商国际上网、旅行 eSIM、本地 SIM 的兼容性、覆盖、套餐、启用步骤、局限、主备方案与离线备份。

### 摄影与必拍点

整条路线都扫描拍摄机会。对核心景点和大众常去地点，即使不值得为摄影改变路线，只要存在可复现的好构图，也给简短、现场可执行的站位、朝向、构图、人物安排和避杂乱建议；旅行价值高但画面普通时给稳妥的纪念照方法，不硬造大片机位。

使用 `必拍 / 值得拍 / 记录即可 / 不建议专程拍`。`必拍` 和重要的 `值得拍` 展开点位、站位朝向、光线、手机构图、时间成本、限制和备选；沿途高价值点可成为正式路线节点。长期默认设备为手机，最多增加 Osmo Pocket 等便携设备，器材不必每次填写，建议以构图和审美为核心。

重点点位默认附 1–3 张实际可见的参考图片；常规知名景点在文字不足以解释构图时至少附一张。每张同时给原始来源、作者 / 机构（可获得时）、查证日期和“借鉴什么”，并标记无人机、长焦压缩、重度后期、特殊季节或不可公开站位等不可直接复现条件。早起可在地点真正值得且安全可行时纳入主路线；长时间等待、明显绕行或牺牲其他核心体验时，只给拍摄强化方案供选择。

### 徒步或户外

必须增加安全摘要：风险颜色、距离、爬升、最高点、预计总时长、最难路段、退出点、折返时间、许可、路线状态和天气核验。可靠路线 / 轨迹必须能在用户自己的徒步软件或可信来源中取得，并核验起终点、关键路径点、山屋、水源、检查站、退出与接驳；没有可靠路径数据时不建议执行。默认不生成打印地图、GPX 或逐路口导航。用户提供已下载轨迹时，审核来源 / 版本、距离爬升、起终点、异常跳点 / 断裂、错误支线、关闭 / 限制路段和关键路径点，交付 `可用 / 条件可用 / 不建议使用` 及待修正项，不把文件审核写成安全认证。

国外徒步把篇幅优先用于：进出交通与天气机动日、许可、每日睡眠海拔、保险与救援、旅行医疗与可用医疗点、山屋 / 营地、食物饮水与卫生、通信充电、现金支付、路线特定装备及购买 / 租借 / 维修。向导和背夫除法律强制外不设默认结论；比较自助、向导、向导 + 背夫的适用条件、价格、资质、包含项、责任、取消和劳动保障，由用户按本次能力与风险选择。

### 博物馆、展览、纪念馆与大型展馆

所有目的地先轻量扫描馆类候选；国家 / 地区首府、知名城市和历史文化城市提高搜索强度。发现真正重要的大小展馆，目的地核心价值明显依赖展馆，或本次路线已经包含重点馆时，必须把展馆作为正式候选和路线锚点研究，而不是只给入口、预约和闭馆提醒。先比较实际公开展出的馆藏 / 展览、不可替代性、展陈质量、与本次兴趣及其他馆的重复度、中文理解条件、时间成本和当前关闭风险，再给出纳入、替代或排除结论。

对重点馆给出中文理解方案、精华 / 深度馆内动线、代表展品及现场观察重点、真实总时长和失败缩短路线。比较官方中文讲解、官方中文语音 / App、持证中文私人导游与行前导读自助四类方案，明确是否值得请中文导游；导游和讲解费用使用当次人数、日期、语言与时长核验，并拆分门票、导游费、语言附加、税费、平台费和小费。

多个重要展馆可使用：

| 展馆 | 真实核心价值 | 本次适配与重复度 | 中文支持 | 建议停留 | 中文导游结论 | 门票与讲解总成本 | 信息确认情况 |
|---|---|---|---|---|---|---|---|

### 纪念品

本次适合购买纪念品或伴手礼时，分别推荐少量自用小物和适合送朋友的轻量礼物。优先考虑有当地辨识度、有趣、便携且价格合适的选择，可包含冰箱贴、明信片、文具、馆藏衍生、小型织物和符合入境要求的包装食品；偏手工、少见或不易复制只是加分项，不是门槛。

按目的地实际价格给出 `低价多人伴手礼 / 中档有质感小物 / 少量特别款`，注明当地货币、人民币约值、适合送谁、推荐购买地、是否顺路、携带 / 易碎 / 保质 / 海关限制。普通低价小物不做复杂的工业化或供应链审查；只有价格较高，或商家明确声称手工、限量、古董、特定产地时，才深入核验真伪与来源。不默认推荐贵重收藏品，也不要求每个景点或展馆都安排购物。

### 费用

需要费用时使用：

| 类别 | 单价与数量 | 小计或区间 | 是否已付 | 来源 / 核验日期 |
|---|---|---|---|---|

明确每人、每房还是每车，并区分必要与可选费用。

### 候选覆盖检查

只有建立了候选母表或用户要求检查遗漏时使用：

| 候选 | 等级 | 本路线 | 原因 / 安排 |
|---|---|---:|---|

覆盖表用于发现遗漏，不要求把所有候选塞回路线。

### 临行清单

需要可执行攻略时，按实际风险选择 `现在`、`T-30 天`、`T-7 天`、`T-48 小时`、`当天` 等节点，不机械输出所有时间层级。

## 4. 质量检查

交付前逐项回答“是 / 否 / 不适用”；关键项为“否”时先修正：

- [ ] 只使用本次任务卡和当前消息中的动态参数，没有继承旧旅行信息。
- [ ] 未填写字段被标记为未知或假设，没有被擅自补全。
- [ ] 只加载并输出与本次任务相关的模块。
- [ ] 动态信息有当前直接来源，来源支持邻近结论。
- [ ] 日期、星期、时区、开放和班次一致。
- [ ] 过夜旅行已主动研究并给出住宿结论；候选使用同日期、人数、房型、税费和取消口径跨渠道比较，并把全程总价、交通、周边闲逛、在地餐饮、夜间返回、入住 / 退房和行李纳入路线。
- [ ] 体验型住宿没有被“少换住宿”机械排除；推荐的景观、房型、时段和住宿内可见性已有依据，搬迁成本与天气失败风险已说明。
- [ ] 便利度拆解到门到门交通、预约、体力和安全返回，而非笼统判断。
- [ ] 公共交通支付已核验到用户钱包 / 卡、具体运营商和票种，并有独立备份。
- [ ] 出租车、网约车、接送、包车或特殊议价交通已有具体价格参考、计价单位、包含项、正规预订方式和书面话术；临时加价、平台外交易、扣留行李和强制附加体验等风险已有预防和求助方案。
- [ ] 马车、骑乘、摩托车或水上特殊交通已核验许可、载客 / 装备、天气 / 水况和动物福利；出现明显安全或动物福利问题时没有因“特色体验”而推荐。
- [ ] 国外旅行已比较现金需求、换汇便利与全部费用；需要依赖手机时已核验确切设备和网络方案，并准备离线备份。
- [ ] 国外旅行已附简洁的运行与安全提示卡；若可信来源反复报告口岸非官方索费，已提前预警并给出合法、安全的处理步骤，没有建议向公职人员付款。
- [ ] 机场 / 航司付费礼宾仅在本次确有价值时出现，且已明确实际覆盖环节，没有与移民、海关或正式政府收费混淆。
- [ ] 路线计入移动、排队、用餐、休息和缓冲。
- [ ] 普通观光旅行未另行说明时采用平衡观光模式，并已用每日起止、核心项目、步行 / 站立量和硬预约说明具体强度；度假 / 高覆盖只在本次有明确依据时切换。
- [ ] 缓冲按风险配置，昂贵演出、定时讲解、不可退预约、末班交通、关键城际交通和返程已留足安全余量；节点已区分硬锚点、核心、可移动和可删减内容，没有使用固定百分比或压缩安全返回来填满日程。
- [ ] 跨越正餐的路线已覆盖代表饮食和可执行的用餐主备选；本地化判断经过当地语言、近期菜单 / 评价和多来源核验，没有复制网红榜单。
- [ ] 酒店和餐厅的法定税、强制服务费、旅游 / 城市 / 度假 / 餐位等附加费、银行卡附加费、自愿小费和押金 / 预授权已按本次场景拆开；不明收费已有索取明细、核对依据、升级沟通、保存凭证和后续申诉步骤。
- [ ] 每天都有起点、终点和返回方案。
- [ ] 预约级别、最后入场和取消规则没有混淆。
- [ ] 费用标明币种、单位、核验日期和必要 / 可选。
- [ ] 重要但未纳入的候选有真实原因。
- [ ] 天气、关闭或误点时有可执行备选。
- [ ] 路线已按季节、日照和典型风险建立骨架；进入可靠预报窗口后使用近期局地天气与预警复核，并写明受影响项目及调整 / 替换 / 取消条件。
- [ ] 备选只针对本次真实风险，并写明触发条件、删改节点、新交通 / 时间及对预约和返回的影响；没有机械复制多套完整日程或默认生成晚出发版本。
- [ ] 徒步任务通过安全闸门；用户能在自己的软件或可信来源中取得可靠路线 / 轨迹，关键路径点、版本与当前状态已有依据。用户提供的轨迹已经检查来源、断裂 / 跳点、错误支线、限制路段和关键节点，并明确审核局限；没有生成用户不需要的打印地图、GPX 或逐路口导航，也没有伪造精确数据。
- [ ] 国外徒步已重点覆盖进出交通、安全、保险与救援、医疗 / 高反、住宿恢复、食物饮水、通信电力、现金、装备和天气机动；向导 / 背夫只在法律或当次条件下判断，并给足背景与价格供用户选择。
- [ ] 所有目的地已轻量扫描馆类候选，首府、知名 / 历史文化城市已提高搜索强度；没有用知名度或游客数量代替实际展出与本次价值，也没有遗漏适合本次的高价值小馆。
- [ ] 最终纳入的重点馆已有可执行馆内动线、代表展品、中文理解方案和真实总时长；中文导游是否值得请已有明确结论，价格、资质、包含项及“免排队”说法已按本次条件核验。
- [ ] 路线中的核心与常规知名景点都已做拍摄可用性扫描；有可复现构图时给手机 / 便携设备可执行的站位、朝向、人物和避杂乱建议，没有用器材或热度代替审美判断。
- [ ] `必拍` 和重要 `值得拍` 已计入日期光线与路线时间，并附有来源清楚、实际可见且解释“借鉴什么”的参考图片；不可复现的无人机、长焦、重后期、特殊季节或非公开机位已标记。
