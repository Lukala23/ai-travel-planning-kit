# 公共交通、票制与支付规则

仅在本次包含公交、地铁、铁路、航班、轮渡或公共接驳时读取。

## 1. 核验实际连接

- 使用运营方的当前站名、时刻、乘车规则、施工和停运信息。
- 明确车站、站台、航站楼或码头是否同址，入口之间需要多久。
- 检查换乘是否要出站、重新安检、边检、提取行李、重新购票或再次支付。
- 核验首末班、班次密度、预约、行李和错过后的下一可行方案。

## 2. 计算门到门时间

计入前往车站、购票 / 充值、候车、步行换乘、找站台、下车后到入口和缓冲。不能用“列车运行 30 分钟”代替完整移动成本。

对必须赶上的航班、火车或轮渡，给出保守到达窗口并解释依据。最短换乘时间不是赶得上的保证。

## 3. 先确认票制，再选择支付方式

逐个运营商核验：

- 单程票、里程 / 分区计价、封顶票价、通票、预约票和座位票之间的关系；
- 是否必须进出站都刷同一张卡、同一部设备或同一支付令牌；
- 换乘优惠、票价封顶是否跨运营商，以及儿童 / 行李是否另购票；
- 车上、站内、App、网站或便利店分别能用哪些支付方式；
- 余额不足、支付失败、手机没电或无网时怎样补票和出站；电子票能否离线显示，还是必须保持联网。

## 4. 支付方案优先级

在确实兼容的前提下，按以下顺序推荐：

1. 用户手机上已经可用、无需新注册的跨境钱包或开放式非接触支付，例如支付宝、微信支付、Apple Pay、Google Wallet；
2. 用户现有的国际非接触实体银行卡；
3. 不需要本地手机号、身份证件或银行账户即可购买的匿名 / 游客交通卡；
4. 现金或纸票作为可用方案和应急备份；
5. 只有当地 App / 钱包在关键场景明显更便利，且节省的时间或费用足以抵消注册、实名、充值、语言和余额退出成本时，才建议注册；存在可靠国际支付替代时优先通用方案。

钱包品牌出现于目的地不等于用户一定能用。必须逐层核验：

- **用户侧**：手机系统、NFC、地区设置、App 版本和绑定卡 / 余额是否可用于境外或交通；
- **受理侧**：具体运营商、闸机、线路、票种和支付场景是否接受该钱包或非接触卡；
- **结算侧**：币种、手续费、汇率、预授权、离线交易、单笔 / 单日限额和退款方式；
- **行程侧**：是否要提前激活、是否依赖网络、能否一部手机为多人购票、换乘和封顶是否保留。

不得把 Alipay+、银联、Visa、Mastercard、Google Pay 等网络或标志的“当地存在”直接写成用户账户“保证可用”。

## 5. 必须提供支付备份

- 主方案与备份不得依赖同一部手机、同一张卡或同一个账户。
- 用户已确认国外旅行可以提前准备实体银行卡和现金。至少准备一种实体支付方式；现金是否用于主支付、应急或完全不需要，以及币种和数额，按当地受理、换汇便利和总成本核验，不机械兑换大量现金。
- 说明手机失电、账户风控、短信验证失败、银行卡拒付和交通卡余额不足时的替代动作。
- 对进出站刷卡系统，提醒不要混用手机钱包与其背后的实体卡，否则可能被视为两个不同支付媒介。
- 国外交通依赖手机票、导航或叫车时，同时执行 `international-travel.md` 的上网方案；交通卡是票价媒介，SIM / eSIM 是通信服务，两者分别判断，不能混写。

## 6. 按本次条件评估便利

- 有大件行李、婴儿车、儿童、长者或无障碍需求时，核验电梯和步行连接。
- 夜间到达时，核验末班与安全接驳；没有稳定回程就调整路线。
- 交通通票、游客卡和匿名交通卡只在计算本次行程后比较，不因“看起来方便”自动推荐。
- 购买交通卡前核验购卡地点、发卡费 / 押金、初始金额、充值方式、余额查询、退款、有效期、遗留余额、一人一卡以及儿童规则。
- 若直接使用用户现有手机支付或非接触银行卡同样获得换乘优惠或票价封顶，不为了形式额外购买交通卡。
- 只有交通卡在本次路线中确实更省钱或明显更方便，且不要求注册本地实名账户时，才把它作为推荐方案。
- 站名、线路名、出口和购票入口使用当地可检索名称，避免只写中文俗称。

交付时给出一张简短的“乘车与支付准备表”：交通段、票种、主支付、是否需预先设置、备份支付和失败处理。
