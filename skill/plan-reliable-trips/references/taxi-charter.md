# 出租车、包车与特殊议价交通规则

仅在需要研究重要出租车 / 网约车路段、机场接送、包车、私人司机、议价价格，或马车、骑乘、突突车、摩托车、传统船只等特殊交通体验时读取。普通城市短途叫车只需给可用正规渠道和必要备份，不自动加载完整模块。专项研究的目标是给出可核验价格、书面确认、安全与伦理判断、风险预警和可执行备选，而不只推荐一个 App。

## 1. 按具体线路判断风险

- 明确起点、终点、日期时段、人数、行李、车型、单程 / 往返、停靠和等待需求。
- 研究该机场、车站、城市、线路和时段的监管、官方上车点、持牌方式、常用 App 与近期投诉；不按国家发展程度笼统判断。
- 对机场、口岸、深夜、偏远景区、跨城、现金议价、信号差和投诉集中路线提高核验强度。
- 使用 `低 / 中 / 高风险` 表示本次组合的风险，并说明可观察依据；不得因个别事件断言所有司机有问题。

## 2. 必须给具体价格参考

对重要交通段尽量使用至少两个独立依据：

- 政府、机场、出租车管理方的固定价或计价器标准；
- 当地实际可用叫车 App 对确切起终点和相近时段的预估 / 固定价；
- 持牌接送或包车公司的当次书面报价；
- 住宿方接送报价，用作安全和便利对照，不自动视为最划算；
- 近期可靠旅客记录只用于校验实际加价、等待与骗局，不单独决定标准价。

输出当地货币区间，并按核验日汇率附人民币约值。说明价格属于固定价、计价器估算、App 动态价还是包车报价，以及是否包含：高速 / 过路、机场费、停车、等待、行李、夜间、跨区、司机餐宿、返空和小费。

无法得到可靠价格时，不编造数字。改为给官方计价公式、获取 2–3 份书面报价的方法、合理谈价步骤和出发前复核节点。

## 3. 选择方式与上车核验

- 综合安全、可追责性、价格和便利，比较官方预付柜台 / 固定价出租车、已核验叫车 App、持牌接送公司、住宿接送与现场议价车。
- 只在官方上车区或清楚约定位置乘车；核对车牌、车型、司机姓名 / 照片，平台支持 PIN 或验证码时使用。
- 分清 App 显示的是固定价、预估价还是按表计价；提前说明哪些调整属于平台规则，哪些不应脱离平台另收。
- 不接受司机要求无正当理由取消平台订单、转为私下现金交易、换车、换司机或改去另一个上车地点；确需变更时通过平台或正规渠道重新下单。
- 截图或离线保存订单、路线、显示金额、车牌、司机、客服入口和目的地当地语言地址；按当地法律和人身安全条件保存沟通与收据。

## 4. 包车和议价必须书面确认

先取得 2–3 个可比报价，再用目的地语言或司机能理解的语言书面确认：

> 请确认：日期和时间，从【A】到【B】，共【人数】人、【行李】件、【车型】；整车总价为【金额＋币种】，不是每人价格；包含【过路费、停车、等待、行李、夜间费等】，除已列项目外没有其他强制费用；付款方式和时间为【方式】。请回复确认。

当次攻略把这段话翻译成当地语言，并保留原文对照。全天 / 多日包车还要写清：每日小时和公里数、允许停靠、超时 / 超公里、油费、路桥、停车、司机餐宿、空驶返程、取消、替换车辆和保险责任。

不向身份和资质不明者全额现金预付；尽量使用可追责平台、持牌公司、住宿方或有正式订单与收据的渠道。订金、尾款和退款节点必须写清。

## 5. 特殊交通和交通体验

马车、骑乘动物、突突车、三轮车、摩托车出租、雪橇、传统帆船 / 小船等既可能承担移动，也可能是独立体验。必须确认：

- 具体起终点或路线、时长 / 圈数、停靠、等待、返程、人数、重量 / 行李和运营时段；
- 价格按整车 / 整船、每人、每小时、每圈还是单程计算，并核验拍照、喂食、讲解、景区门票、等待、返程和小费是否另收；
- 官方售票点、许可 / 保险、允许运营区域、上下客点和是否存在更正规且价格透明的渠道；
- 摩托车类的头盔、载客限制和道路风险；水上项目的核定载客、救生衣、天气 / 水况、夜航和返程；
- 动物运输 / 骑乘的天气与温度、动物是否跛行、受伤、消瘦、呼吸异常、过载或遭粗暴驱赶。出现明显福利问题时不推荐乘坐，不以“当地特色”为理由忽略。

使用与包车相同的书面确认原则，并明确“体验结束地点”和“是否必须另付返程”。警惕“免费试坐 / 先拍照”、短程临时延长、下车后改成每人价、强制购买照片 / 饲料、把约定路线缩短或到偏僻处再索价。

## 6. 常见异常与提前规避

按目的地核验并提醒可能出现的：假冒司机、车牌不符、计价器未开 / 加速、故意绕路、币种偷换、整车价变每人价、虚构机场 / 行李 / 过路费、刷卡终端做手脚、要求取消 App、平台价外强行加价、拒绝找零，以及以行李或车门施压。

- 护照、手机、现金、药品和关键电子设备尽量随身，不放后备箱；大件行李不可避免时，记录车辆与行李状态。
- 上车前再次确认目的地、总价 / 计价方式和付款方式；现场议价未确认前不装行李、不出发。
- 不把手机交给司机操作，不透露验证码或支付密码，不扫描来源不明的支付码。
- 行驶中关注路线，但不要因普通绕行立即对抗；发现明显异常时优先要求在官方、酒店、机场或人多有监控的地点结束行程。

## 7. 临时加价或扣留行李时

- 个人安全优先于财物和价差，不进行肢体争夺，不跟随司机前往第二地点。
- 在安全、公开和有监控的位置明确指出 App / 书面约定金额，请对方通过平台调整并提供正式收据；不要被迫在其手机上输入账户或验证码。
- 使用 App 紧急 / 客服功能，并联系当次已核验的机场 / 车站安保、酒店前台、旅游警察或当地警方；紧急号码必须在出发前查证并离线保存。
- 若司机扣留行李，记录车牌、司机、地点、订单和索价证据；不要自行拦车或强行开后备箱，由安保或警方介入。遭遇即时威胁时以脱离危险为先，事后保留证据投诉、报警或申请平台退款。
- 攻略不得保证警方、平台或退款一定解决问题；必须提供主渠道、第二联络渠道和安全替代交通。

## 8. 交付格式

对机场接送、跨城、包车、特殊议价交通及其他高摩擦段给出：

| 路段与时段 | 首选方式 / 预订入口 | 价格参考及依据 | 包含 / 可能另付 | 上车与书面确认 | 主要风险 | 失败备选与求助 |
|---|---|---|---|---|---|---|

- 价格注明核验日期、当地货币、人民币约值、价格性质和适用车型 / 人数。
- 特殊交通同时注明计价单位、路线 / 时长、体验包含项、安全装备、动物福利或水况等退出条件。
- 附当地语言的总价确认话术；高风险线路再附“我只按 App / 书面确认金额付款，请通过平台处理争议”等简短句子。
- 把当地官方求助号码、App 客服 / 紧急入口、机场 / 车站安保和住宿联系方式列入离线交通安全卡。
