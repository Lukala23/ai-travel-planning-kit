# 旅行健康与医疗规划规则

当预计睡眠或活动海拔约 2450–2500 米以上，存在疫苗 / 预防用药或入境健康证明问题，携带受管制药品、针具、冷链或医疗设备，用户提及会影响旅行的健康条件、慢性病、严重过敏、孕期或既往高反，行程偏远且医疗 / 撤离会改变可行性，或用户主动要求健康医疗规划时读取。

普通城市旅行只有常规食水、日晒、蚊虫或轻微气候风险时，只在路线中给简短实用提醒，不加载完整健康问卷或健康准备卡。本模块用于规划和风险分流，不诊断疾病、不代替医生，也不擅自给出个体处方或剂量。

## 1. 先做轻量健康风险扫描

按确切目的地、过境点、日期、季节、海拔、住宿环境和活动核验，而不是给整个国家贴统一标签。至少扫描：

- 官方入境健康要求与旅行健康建议；
- 疫苗可预防疾病、疟疾等需评估预防用药的暴露、当前疫情或公共卫生事件；
- 蚊虫 / 蜱虫、食物与饮水、热、寒、日晒、空气质量和动物接触；
- 预计睡眠与活动海拔、上升速度、偏远程度和撤离时间；
- 常用药跨境、医疗服务可达性、语言、付款和旅行保险配合。

不要因为目的地位于热带或亚热带就自动输出完整医疗章节；只有风险、用户条件或决策价值达到触发标准时深入研究。相反，不徒步的高海拔城市、邮轮、探亲、商务或普通观光也可能触发。

## 2. 只收集判断所需的健康条件

需要时询问：

- 路线、日期、停留时长、预计睡眠 / 活动海拔和活动强度；
- 年龄段、孕期 / 备孕、行动或感官协助需求；
- 会影响旅行的慢性病、严重过敏、既往高反或近期重要治疗；
- 常用药的通用名、剂型、储存 / 冷链、针具或设备需求，以及大致数量；
- 常规和旅行相关疫苗是否已完成或未知；
- 用户希望讨论的风险与可接受的医疗可达性。

不索取身份证件号码、完整病历、处方编号、保险账号或与规划无关的诊断细节。交付文件只保留必要类别，建议用户把完整药单、医嘱和紧急联系人保存在自己的安全位置。

## 3. 行前临床与公共卫生核验

- 分开写“入境 / 登机强制要求”和“基于暴露风险的健康建议”；一张证书可能是法律文件，也可能只是医学建议，不能混用来源。
- 优先使用目的地 / 居住地公共卫生机构、世界卫生组织、主管边检 / 使领馆和合格旅行医学机构的当前页面。当前疫情、疫苗和预防用药属于动态信息。
- 需要接种、预防用药、慢性病调整、孕期评估、高海拔建议或复杂活动时，提示尽早咨询旅行医学或熟悉用户病情的合格临床人员；不要用固定“提前几天”替代具体疫苗疗程、出发日期和个人情况。
- 把需临床决定的事项标成 `需专业评估`，不要自行判断禁忌、相互作用、处方药选择或剂量。
- 用户临近出发才提出时，不默认“已经来不及”；核验仍可能有效的措施、替代路线和风险降低方案，并建议尽快获取专业意见。

## 4. 处方药、非处方药与医疗设备

- 对目的地和所有过境点核验受控药物、精神 / 麻醉类药物、注射用品、液体、氧气、冷链和电池设备的海关、航空及安检规则；本国合法处方不代表可跨境携带。
- 建议在原包装中携带合理旅行用量，并准备通用名、用途和剂量表，以及按目的地要求提供的处方、医生证明、翻译、公证或事前许可；具体文件必须由主管机构确认。
- 分开随身与托运行李；关键药品、急救药、医疗设备和必要文件通常要有延误 / 丢行李备份，但必须遵守液体、针具、电池和冷藏规定。
- 核验时区变化、储存温度、冰箱可靠性、供电 / 插头、备用电源、耗材和目的地能否合法补配。不要建议用户未经医生确认自行改变用药时间或剂量。
- 使用国际通用名而非只写品牌；目的地药房同名或近似包装不能证明成分、剂量或真伪相同。

## 5. 高海拔不只属于徒步

- 对预计睡眠或活动海拔约 2450–2500 米以上的城市、观光缆车、公路、火车、航班落地和徒步都读取本节；以睡眠海拔、上升速度、到达前适应和个人既往反应判断，不只看景点最高点。
- 体能好不代表不会出现高海拔疾病；曾经无反应也不能保证本次安全。既往有明显高反、心肺疾病、孕期或其他相关状况时，行程预订前交给合格医生评估。
- 路线优先渐进升高，给最初阶段较轻活动、睡眠与补水空间；避免落地后立即进行高强度活动、饮酒或镇静性安排。具体上升与预防用药方案必须依据权威临床建议和个人评估。
- 每个高海拔阶段写明睡眠海拔、最高活动海拔、前一晚海拔、可下降地点、交通与预计医疗可达时间。
- 出现症状时不继续强行上升。交付中引用权威机构的症状分级与行动建议；出现呼吸困难、意识改变、走路不稳、昏厥或其他严重 / 快速恶化情况时，应立即停止行程并寻求当地急救或紧急下降，不在聊天中等待诊断。

## 6. 食水、媒介与常见环境风险

- 核验目的地自来水、制冰、刷牙、生食、乳制品和街头食品的当前权威建议；不要用“当地人喝”或酒店星级推断旅行者安全。
- 有蚊虫、蜱虫或其他媒介风险时，给出覆盖皮肤、驱避剂、蚊帐 / 空调、活动时段和住宿环境等可执行预防，并核验是否需要临床评估预防用药。
- 对高温、强日晒、寒冷、干燥、空气污染和山火烟霾说明暴露时段、衣物 / 补水 / 休息、室内替代和临行监测入口。
- 对旅行者腹泻、中暑、晒伤、虫咬、晕动等常见问题，只给权威的一般预防、自我照护边界和就医触发条件；有慢性病、孕期、婴幼儿、老年或症状严重 / 持续时降低就医阈值。
- 不因“可以买到药”而推荐来源不明、处方不清或可能假冒的药品。

## 7. 目的地医疗体系与就医路径

按行程复杂度核验：

- 当地急救号码、使领馆或官方医疗协助入口；
- 适合本次风险的诊所 / 医院层级、24 小时能力、语言与到达时间；
- 先付费还是可直接结算、押金、银行卡 / 现金、保险预授权和收据 / 病历取得方式；
- 合法药房与处方要求、周末 / 夜间服务；
- 偏远地区救援、转诊、陆路 / 航空医疗撤离及天气限制。

不把“附近有医院”写成具备创伤、高海拔、儿科、产科或重症能力。高风险或偏远路线至少给主医疗点、升级转诊点和无法按原路线继续时的撤离方向，并与 `travel-insurance.md` 的保障地域、活动和撤离条款核对。

## 8. 慢性病、无障碍与同行协作

- 为慢性病或医疗设备预留药量、延误余量、休息、用餐、储存、充电和复诊 / 检查窗口；所有具体调整由熟悉病情的临床人员确认。
- 核验航空公司或运营方的医疗设备、辅助器具、氧气、冷藏、优先协助和证明要求，不能仅依据机场通用说明。
- 同行人只需知道用户愿意共享的应急行动、药品 / 设备位置和求助入口；不在公开攻略写入完整健康隐私。
- 对独行、语言困难或偏远行程，增加定时联络、翻译卡、离线医疗信息和未按时联系的升级步骤。

## 9. 按需要交付健康准备卡

触发本模块后只选择与本次风险有关的项目；风险确实影响准备、路线或求助时再交付健康准备卡，不为模板完整补齐：

1. `健康风险较低 / 可通过准备管理 / 需专业评估后决定 / 当前不建议执行 / 尚无法判断`；
2. 触发风险、适用路线 / 日期和证据日期；
3. 行前临床事项、疫苗 / 预防用药待确认项及最晚有意义的办理节点；
4. 药品 / 设备的合法携带、储存、备份和文件；
5. 高海拔、食水、媒介、气候 / 空气质量的本次行动；
6. 最近适合的医疗点、紧急号码、付款 / 保险流程和撤离升级；
7. `现在 / T-30 / T-7 / T-48 / 当天` 中真正相关的复核项。

所有临床结论说明其来源与边界。若缺少用户健康条件或无法获得权威当前信息，明确保留未知，不用通用文案制造安全保证。
