# 信息检索与核验规则

## 1. 先判断信息是否会变化

下列信息一律视为动态信息，必须在当前任务中联网核验：

- 营业日、开放时间、最后入场、季节关闭和临时关闭；
- 门票、预约政策、放票时间、通票适用范围；
- 博物馆 / 展馆的当前展览、展厅关闭、代表展品是否在展、馆内动线、中文导览、人工讲解、外部导游政策与讲解价格；
- 公交、铁路、轮渡、接驳车时刻和停运；
- 签证、入境、道路、停车、限行、无人机与保护区规定；
- 步道开放、施工、落石、火险、雪崩、涉水、潮汐和许可证，以及用户徒步软件 / 可信来源中路线数据、版本与关键路径点的可获得性；
- 天气预报、空气质量、日出日落、潮汐、积雪与水位；
- 拍摄点当前可达性、摄影限制、遮挡 / 施工、人流条件、太阳方向，以及用于构图说明的参考图片来源与拍摄条件；
- 住宿的合法状态、房型库存、全程价格、税费、押金、取消和入住规则；
- 餐厅 / 市场的营业状态、店址、菜单、价格、预约、休息日、食品监管信息，以及税、强制服务费、餐位费、刷卡附加费和小费惯例；
- 旅行团、车辆、价格、库存和汇率；
- 支付钱包、银行卡受理、ATM / 换汇费用、漫游 / SIM / eSIM 套餐、设备兼容和网络覆盖；
- 出租车固定价 / 计价标准、叫车 App 覆盖与估价、接送 / 包车 / 特殊交通报价、机场上车点、运营资质、安全装备、动物福利规则和交通骗局；
- 口岸正式收费，以及官方旅行提示和可信近期来源中反复出现的非官方索费风险；
- 任何使用“目前、最新、现在、今年、届时”等表述的结论。

历史背景、建筑年代等相对稳定的信息也要有可靠依据；若来源互相矛盾，保留分歧。

## 2. 来源优先级

按以下顺序选择能直接支持结论的页面：

1. 政府、国家公园、保护区、景点、博物馆、铁路或公交运营方、道路管理方、气象和应急机构的官方页面；
2. 当地旅游局、权威文化遗产机构、官方地图或官方发布的 PDF / GPX；
3. 主流地图、可信出版物或专业户外数据库，用于位置、体验和交叉检查；
4. 近期游客记录，用于排队、施工现场感受、容易走错的岔口等非官方经验，不得单独证明开放、安全或法律状态。

优先打开具体页面，不引用搜索结果页、聚合页或无日期摘要。对非中文目的地，同时使用当地语言或官方英文名称搜索。

住宿和餐饮另按用途分工：住宿 / 餐厅官方渠道支持房型、设施、菜单与政策；预订平台支持当次库存、同口径总价和渠道条款；Google Maps、当地点评 / 预订平台及近期顾客内容用于现场体验和反复问题。任何单一平台的评分、排序或搜索摘要都不能独立证明“最值得”或“本地人最爱”。

酒店和餐厅收费优先使用税务 / 地方政府、消费者主管机构、住宿或餐厅的当前条款 / 菜单和预订确认。近期顾客账单与评价只用于发现可能存在的收费项目；不得仅凭一张账单或一个比例，把某项费用认定为法定税、强制服务费或全国惯例。交付时分开写法定税、强制附加费和自愿小费。

口岸正式费用优先使用移民、海关、使领馆或其他主管机构页面。非官方索费风险使用官方旅行提示并与多个可信、近期且相互独立的来源交叉检查；个别帖子只能形成待查线索，不得据此给国家或群体贴标签。机场 / 航空公司的商业快速服务与移民、海关的公权力流程必须分开核验，第三方服务不得证明能够优先通过边检或海关。

博物馆与展馆优先使用官方开放 / 票务页、当前展览页、馆藏数据库、展厅地图、导览与外部导游政策；馆藏数据库中的作品不能自动视为当前陈列。馆藏价值与策展判断可结合文化主管机构、博物馆协会、大学 / 研究机构、展览图录和可信专业文化资料；近期游客内容只用于交叉检查排队、找路、中文服务实际可用性和现场体验。中文导游价格以馆方、持牌导游名录、合法运营方当前页面或针对确切条件的书面报价为准，不用旧游记猜行情。

摄影参考图优先使用景点 / 目的地官方页面、文化机构、旅游局、可追溯原作者页面和 Wikimedia Commons 等来源清楚的图片；地图与社交图片用于交叉检查近期现场和普通游客可复现性。展示图片时同时附原始来源页面、可获得的作者 / 机构和查证日期，不引用无来源转载或只给搜索结果页。参考图中的无人机、长焦压缩、重度后期、特殊季节、封闭区域和不可公开站位必须识别，不能据此承诺用户能拍出同样画面。

出租车、网约车、包车和特殊议价交通价格优先使用监管机构 / 景区 / 机场固定价、平台对具体路线的当前估价和持牌运营方书面报价。近期旅客报告用于发现加价与骗局模式，不能单独证明标准价格；马车、骑乘或传统船只等还要使用主管机构、运营规则和现场近期证据核验安全与动物福利。无法核验到具体路线或时长时只给获取报价的方法，不编造行情。

## 3. 核验强度

- 安全、合法性、昂贵且不可退预订：至少两个相互独立来源，其中至少一个为官方来源。
- 开放时间、门票、预约和班次：至少一个直接官方来源；若官方信息模糊或过期，再找第二来源并标注冲突。
- 地图耗时与距离：视为估算；对关键连接段用第二种方式交叉检查。
- 用户生成内容：只可支持主观体验或发现待查问题。

不得以“多个网站都抄了同一段话”当作独立证据。

## 4. 日期与天气

- 先把相对日期换算为完整年月日和星期，并写明采用的解释；存在歧义时不得静默挑选具体日期。
- 用户日期在可靠预报窗口内时，使用目的地官方气象或高质量预报，并写明预报更新时间。
- 日期超出可靠预报窗口时，只提供历史气候或季节性风险，明确写“不是届时天气预报”，并列出 `T-7 天`、`T-48 小时` 等复核节点。
- 涉及山地、海岸或峡谷时，查询局地预报；城市预报不能替代山顶、步道或海况。
- 所有日期写完整年月日和星期，避免“明天、周末”在文档中过期。

## 5. 冲突处理

遇到来源冲突时：

1. 比较发布机构、适用日期、更新时间、时区和适用对象；
2. 采用最新且最接近实际运营方的规则；
3. 若仍无法判断，写出两个版本及风险，不替用户拍脑袋；
4. 对会导致无法进入、滞留或危险的冲突，标记为出发前必须人工确认。

“页面未提及”不等于“不需要预约 / 没有风险 / 可以通行”。

## 6. 引用与状态写法

把引用放在它支持的句子或表格单元格附近，使用可点击的直接链接。对关键动态信息注明核验日期。

需要向用户显示时，标题使用“信息确认情况”，不要写抽象的“证据状态”。统一使用以下直白表述：

- `已查证`：当前官方或高质量直接来源明确支持；
- `出发前复查`：当前可用，但临近出发仍可能变化；
- `取决于条件`：取决于天气、许可、交通或尚未确定的用户条件；
- `尚不确定`：来源冲突、过期或无法访问；
- `规划判断`：由多个事实推导出的路线建议，不是来源原话。

这些词只说明信息是否可靠和是否还会变化，不参与景点 A / B / C / D 价值分级。

严禁编造网址、引用、票价、坐标、班次或“官方建议”。若工具无法访问网页，明确说明核验能力受限。
