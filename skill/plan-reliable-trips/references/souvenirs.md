# 纪念品、伴手礼与本地购买建议

仅在用户希望带回小物 / 送朋友礼物，或购买已经成为明确路线节点时读取。经过展馆、文化景点、市场或手工艺区域只做轻量价值扫描，不自动加载本文件或安排购物。纪念品只是旅行辅助，不建立僵硬收藏标准，也不默认安排贵重购物。

## 1. 使用软偏好，不把随口想法变成硬门槛

用户偏好有当地辨识度、有趣、便于携带且价格不过高的物品；偏手工、少见、不易复制是加分项，不是强制条件。

- 冰箱贴、徽章、钥匙扣、明信片、文具、布艺小物、博物馆衍生、小包装当地食品等都可以进入候选，不因属于普通商品就自动排除；
- 不展开与实际购买决定无关的生产方式或设计分类细节；
- 只有价格较高，或商品明确宣称纯手工、限量、古董、特定材质 / 产地时，才进一步核验制作、真伪和溢价；
- 默认不推荐昂贵收藏品、珠宝或大型易碎物；确有突出价值时只作为可选项，并说明为什么值得。

## 2. 推荐自己留念与送朋友两类

### 自己留念

优先考虑能让人联想到本次目的地、设计有趣、质量尚可、带回后愿意使用或摆放的物品。馆藏衍生、本地插画、城市符号和小型工艺品可以推荐，但不因“限定”二字自动判断值得。

### 送朋友的小礼物

- 适合多人分送、单价不高、体积小、包装稳妥且不容易产生口味 / 尺码负担；
- 当地食品、调味料、茶饮、香氛、化妆品等必须先检查保质期、液体、过敏原、检疫和入境限制；
- 提醒适合送什么人、是否需要托运、一次购买数量和包装方式；
- 不为了“必须带礼物”推荐没有地方特色或明显不值的通货。

## 3. 按当地价格水平给分档建议

不设跨国家固定金额。按本次目的地、汇率和购买数量给当地货币与人民币约值，可使用：

- `低价多人伴手礼`：适合多买几份，重点看有趣、便携和不显廉价；
- `中档有质感小物`：适合自己或关系较近的人，重点看设计、质量和地方联系；
- `少量特别款`：只有确实值得时提供，不默认为必买，也不延伸到高价收藏。

每档不用凑满。若目的地没有好的低价礼物或某档明显不值，直接说明。

## 4. 比较购买地点

按本次路线比较实际可到达的渠道：

- 博物馆 / 景点商店：馆藏或地点关联、设计、授权与溢价；
- 创作者店、工坊、合作社：独特性、营业 / 预约和价格；
- 本地市场、书店、设计店和普通零售：选择、质量、包装和退换；
- 超市、食品店或药妆店：适合可消耗小礼物，检查规格、保质期和携带；
- 机场 / 车站：作为忘买或时间不足的备选，说明是否有明显溢价。

“更便宜、最顺路、更有地方性、最适合送人”分别判断，不强行归为同一家店。比较同规格、同材质、同包装和是否含税的价格；小额普通纪念品无需做过度复杂的供应链调查。

## 5. 简洁购买卡片

只对真正适合本次的物品给建议：

| 物品 | 适合自己 / 送谁 | 当地特点与有趣之处 | 价格档与当前区间 | 推荐购买地 | 携带 / 保质 / 海关提醒 | 是否值得 |
|---|---|---|---|---|---|---|

- 价格、库存和营业时间属于动态信息，注明核验日期；无法确认时写“现场复查”，不猜库存；
- 给出少量明确推荐，不用几十种通用商品填满攻略；
- 确有实用价值时补充推荐规格、数量和便宜备选；普通冰箱贴等无需写冗长的材质与工艺报告。

## 6. 基础安全与合法性

- 不推荐疑似盗掘文物、假古董、濒危动植物制品、违禁品或违反进出口规则的物品；
- 宗教、原住民或传统图样涉及使用禁忌时简要提醒；
- 液体、粉末、食品、种子、肉奶、药品、易碎和大尺寸物品检查航空、海关与检疫限制；
- 议价只在当地确属常规时建议，保持尊重，不把压到最低价当作核心目标。
