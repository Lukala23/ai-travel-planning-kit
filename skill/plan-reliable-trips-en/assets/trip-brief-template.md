# Optional advanced per-trip information brief

> Ordinary tasks can be described in natural language; do not require or load this form by default. Copy it only for a complex trip, a large set of constraints, or when the user wants a durable structured brief. It never becomes a permanent profile. Fill relevant modules only; use `Unknown` or `Not applicable` as needed.

## Rules

- When using this template, complete table A first and select other tables by current modes. Without the template, extract the minimum core facts from the user's message instead of loading the whole form.
- “Core” means the planner must know its state, not that every answer is already available.
- Travel modes can combine in any order.
- Mark confirmed bookings, fixed times, and safety restrictions as hard constraints.
- Never include passport/identity numbers, payment credentials, or a private home address.
- Natural language is sufficient. Summarize only ambiguous parameters that need confirmation; do not print the complete internal brief by default.
- When travelers, days, budget, and its basis are already clear, use them directly instead of repeating questions for form completeness.
- For destination exploration, destination plus the question may be enough. For an executable daily route, provide dates, duration, endpoints, travelers, budget, core goals, and hard constraints where possible.
