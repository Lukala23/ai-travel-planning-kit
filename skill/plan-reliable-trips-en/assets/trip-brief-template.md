# Per-trip information brief

> Copy and complete a new brief for every trip. It does not become a permanent profile. Fill only relevant modules; use `Unknown` when undecided and `Not applicable` when irrelevant.

## Rules

- Review table A for every trip; load other tables by current modes.
- “Core” means the planner must know its state, not that every answer is already available.
- Travel modes can combine in any order.
- Mark confirmed bookings, fixed times, and safety restrictions as hard constraints.
- Never include passport/identity numbers, payment credentials, or a private home address.
- Natural language is acceptable; the agent should turn it into a brief for confirmation.
- For destination exploration, destination plus the question may be enough. For an executable daily route, provide dates, duration, endpoints, travelers, budget, core goals, and hard constraints where possible.
